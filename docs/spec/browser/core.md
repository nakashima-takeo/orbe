# 内蔵ブラウザ

端末やエディターを 1px も動かさずに Web ページを重ねて閲覧するための、ウィンドウ最上層のブラウザ層。端末で開発サーバーやドキュメントを見ながら確認する作業で、別ウィンドウを行き来したり端末の桁数・行数を崩したりしないための器。

## 3 層モデルと表示状態

ウィンドウの表示領域は 3 層で重なり、ブラウザは常に最上層に立つ（→ [chrome/layout](../chrome/layout.md)）。

- **端末 / ボード（Z=0）**: 不動の土台。ブラウザの開閉・幅変更・全面切替のいずれでも端末の寸法は変わらず、pty のリサイズ（`SIGWINCH`）は発生しない。
- **エディター（Z=1）**: 連ごとの面（→ [editor/faces](../editor/faces.md)）。
- **ブラウザ（Z=2）**: ウィンドウに 1 面。自由スペース表示中は workspace やタブを切り替えても開閉状態・シート幅比率・表示ページをそのまま保持し、ローカルスペース表示中は切替先 workspace に紐づくローカルスペースの中身へ切り替わる。

ブラウザの表示状態は「閉」「右シート」「全面」の 3 態で、起動時は常に閉じた状態で始まる。シート幅比率・前回アクティブスペース・各スペースのタブ構成と選択位置・閉じたタブ履歴は専用 DB（→ [platform/persistence](../platform/persistence.md#ブラウザの-db)）から復元し、`⌘B` で開いた時点で前回状態の表示を起こす——起動直後の WebKit 生成ゼロと端末フォーカス契約を両立するため。

- **`⌘B`**: フォーカス位置を問わず、0 タブ・ボード選択中を含めて純粋トグルで開閉する。閉じていれば右シートを開いて焦点をブラウザへ移し、開いていれば（右シート・全面とも）閉じて下層へ焦点を戻す。
- **下層へ移る操作**: タブ行のクリック・タブ切替・新タブ・閉じたエージェントの復元・ボード選択・`focus_tab`・`⌘E`・`⌘⇧F`・`open_file`・`open_diff` では、全面表示中ならブラウザを閉じて下層へ移り、右シート表示中なら右シートを残したまま焦点を下層へ譲る。全面ブラウザ表示中の `⌘E` はエディターの開閉を反転せず、全面を閉じてエディターを開く。自動化の知らせ（メニューバーのピル・通知センター）のクリックで Home ボードの詳細へ移るときは、ボード右側の詳細欄を見せるため全面だけでなく右シートも閉じる（→ [platform/automation](../platform/automation.md#回の知らせ)・[chrome/menubar](../chrome/menubar.md)）。
- **workspace 切替・背景タブの閉鎖**: ブラウザの開閉・幅比率と、全面または右シート焦点中のフォーカスを保つ。自由スペース表示中は表示ページも動かず、ローカルスペース表示中のみ切替先 workspace のローカルスペースへ表示を切り替える。

## プロファイルとスペース

ブラウザはアカウントや Cookie の境界を表す「プロファイル」と、作業文脈ごとのタブのまとまりを表す「スペース」を多対 1 に直交させて持つ。複数の作業スペースで同じアカウントを共有しつつ、私用と業務のログインセッションや MCP 公開範囲を厳格に分離するため。

- **プロファイル**: Cookie・`localStorage`・MCP 読み取り可否（`mcpAllowed`）の単位。各プロファイルはランダム UUID を識別子として独立した WebKit データストアを持ち、異なるプロファイルに紐づくタブ間では Cookie と `localStorage` を共有しない（同一プロファイル内の複数タブ間では共有する）。プロファイルは最低 1 件残る不変条件を持つ。
- **自由スペース**: 全 workspace で共通のスペース。workspace を切り替えても表示中のページとタブ構成をそのまま保つ。
- **ローカルスペース**: 各 workspace（Home を含む）に 1 対 1 で対応するスペース。対象 workspace が初めてアクティブになった時点で遅延作成し、表示名は対象 workspace の名前を参照する。workspace を閉じて削除すると、そのローカルスペースと配下タブ・閉じたタブ履歴も連動して片づく（起動時に `workspaces.json` に無い未知 workspace のローカルスペースは自動削除しない——退避等で一時的に workspace 構成が初期化された際にブラウザ側まで巻き込んで失わないため）。
- **初回起動時の既定構成**: プロファイル 2 種（`personal`［MCP 非公開］・`work`［MCP 公開］）と自由スペース 3 種（個人［`personal`］・仕事［`work`］・調査［`work`］）を投入し、初回アクティブは現在 workspace のローカルスペース（`work` 紐づけ・タブ 0 枚の新しいタブ画面）とする。
- **プロファイル変更と削除**: スペースに紐づくプロファイルを変更すると、そのスペース配下の生成済み WebKit 実体をすべて破棄し、アクティブ表示中であれば新しいプロファイルのデータストアで起こし直す。プロファイルを削除するときは、参照スペースを別のプロファイルへ付け替える前に該当プロファイルの全 WebKit 実体を解放・アンマウントして DB へ削除待ちを記録し、常用環境かつ DB 利用可能時のみ OS 側の永続データストアを非同期削除・再試行する（DB に無い未知ストアの一括掃討は行わない）。

## タブ構成・12 時間自動整理・閉じたタブ復元

- **タブ区分**: 各スペースのタブは `Favorites`（自由スペースのみ）・`PINNED`・`TODAY` の 3 区分を持つ。ローカルスペースには `Favorites` を置かない。タブを閉じたときの次選択は、同スペースの同区分内で直後 → 直前 → 同スペース他区分先頭（`Favorites` → `PINNED` → `TODAY`）の順で決める。
- **12 時間自動整理**: 最終閲覧・操作時刻から 12 時間以上経過した `TODAY` タブを壁時計タイマーで自動削除する（スリープ復帰およびシステム時計変更時に再計算する）。起動時はアクティブだったタブも含めて全スペースを一律整理し、運転中は「ブラウザが開いて表示中のアクティブタブ 1 枚」だけを目の前から消さないよう保護する。
  - `TODAY` タブの最終閲覧・操作時刻は、タブ作成・`TODAY` への降格・URL 遷移確定に加え、表示ライフサイクルに合わせて更新する——ブラウザを開いたとき・閉じたとき、および開放中にタブ・スペース・ローカル workspace を切り替えたときに、離脱直前と切替後のアクティブ `TODAY` タブを更新する。閉鎖中の切替や起動時は延命しない。
  - 自動整理で消えたタブは閉じたタブ復元履歴へ積まない——古い放置タブの一括整理で直近の誤閉鎖履歴が押し流されないようにするため。
- **閉じたタブ復元**: 手動閉鎖または手動一括整理で閉じた URL 付きタブを上限 50 件まで DB に保持する。履歴は元のスペースに紐づけ、スペース削除時に一緒に消去する——非公開プロファイルの履歴が別プロファイルのスペースへ越境復元される事故を構造上防ぐため。復元時は生存する自由スペースまたは現在 workspace のローカルスペースに属する最新 1 件を選び、元のスペースの `TODAY` 末尾へ戻して選択する（他 workspace のローカルスペース由来の履歴はスキップし、その workspace へ戻ったときに復元対象となる）。

## 右シートの見た目・幅変更・全面切替

右シートは上・右・下の余白を持たない右エッジシートとして下層の上に重なる。ツールバー地と本体地は透過設定（`ChromeTranslucency`）を適用せず、常に不透明度 100% で塗る——背後の端末文字が透けて濁るのを防ぐため。

- **境界と焦点の表現**: 右シートの左端に細い境界線と左落ち影を置く。右シート表示中かつブラウザに真の焦点がある間（非めくり時）は左層へ薄い暗幕ベールを掛け、どちらの面に焦点があるかを一目で示す。下層へ焦点が移ると暗幕ベールを消し、左落ち影を浅くし、ツールバーの背景は 100% 不透明のまま中のアイコン・文字だけを落ち着かせる。シート上へポインタを乗せると影とツールバーは通常の濃さへ戻る（暗幕ベールは真の焦点時のみ）。
- **左端ドラッグ**: 右シート左端の内側にドラッグ当たりがあり、ホバーまたはドラッグ中のみ左端に細いアクセント線が現れ、左右リサイズカーソルになる。ドラッグ中は左内側にスナップ表示（現在の幅比率・全面吸着・離すと閉じる）を浮かべる。
  - 通常域では下限〜上限の範囲で連続的に幅が追従し、通常域内で離したときだけその比率を DB へ確定保存する（ドラッグ中は保存しない）。
  - 左端の閾値を超えると全面吸着プレビューになり、離すと全面表示へ移る（ドラッグ開始前の確定比率を記憶したまま残す）。
  - 右端の最小幅を下回ると閉じプレビューになり、離すとブラウザを閉じる（次回開くときはドラッグ開始前の確定比率で開く）。
  - ドラッグ中にウィンドウが非アクティブになった場合やビューが窓から外れた場合は安全に中断し、ドラッグ開始前の確定比率とカーソル状態を復元する。
- **ダブルクリックと切替ボタン**: 右シート左端のダブルクリックで全面表示へ切り替える。ツールバー右端の切替ボタンで右シート ⇄ 全面を往復でき、右シートへ戻すと記憶した比率を復元する。狭幅ウィンドウでもシート幅が破綻しないよう、ウィンドウ幅に合わせて収める。

## クローム・サイドバー・新しいタブ・キー処理

ツールバー（サイドバー開閉・戻る・進む・再読込 / 停止・URL 欄・全面めくり案内ピル・全面 ⇄ 右シート切替）、Arc 式サイドバー（横並び ⇄ 狭幅オーバーレイ、モード別開閉記憶、プロファイル・自由スペースのビュー内ポップオーバー）、新しいタブ画面、およびブラウザ焦点中のキー優先順（`⌘T`・`⌘W`・`⌘R`・`⌘⇧T`・`⌘S`・`⌘B`・`Esc`）の詳細は [chrome](chrome.md) を参照。

## ⌥ 長押しによる単層めくり

`⌥` だけを 0.2 秒押し続けると、常に「いま最上層にある 1 枚だけ」をめくって直下の層を見せる（判定規則と許容は [editor/faces](../editor/faces.md) の ⌥ と共通）。ブラウザが開いている間は、下にエディターが開いていてもブラウザだけがめくられ、エディターは動かず全幅で見える。

- **右シート表示中**: 右シート全体（バーと本体）を隠し、ウィンドウ右端に細いアクセント線だけを残す。
- **全面表示中**: 100% 不透明な全幅ツールバーだけを上に残し、バーより下を透明にして直下の層を見せる。ツールバーには直下の層に応じた案内ピル（`⌥`＋「端末を表示」/「エディターを表示」/「ボードを表示」/「ウィンドウを表示」）を出す。
- **焦点と入力**: めくり中はビューを非表示にせず不透明度だけで透過し、全面めくりでツールバーの案内ピルを出し入れしても URL 入力欄の階層を保ち続けるため、Web ページおよび URL 欄編集中の焦点・入力内容・IME 変換・再生状態を途切れさせない。めくり中はクリックとスクロールをブラウザ層が吸収し、下層エディターの押下監視（開いている一覧の閉鎖など）も抑止する。
- **通知制御**: 全面ブラウザが非めくりで覆っている間は端末が見えないため完了通知（`done`）を抑制せず、右シート表示中・全面めくり中・全面解除時に端末が見えれば通知を抑制・消費する（→ [chrome/chrome](../chrome/chrome.md)）。Home ボードの自動化通知については、ブラウザが非めくりで開いている間（全面・右シートとも）はボードの詳細欄が覆われるため抑制せず、`⌥` めくり中またはブラウザ閉鎖時のみ抑制対象とする（→ [platform/automation](../platform/automation.md#回の知らせ)）。

## 遅延起動と隔離

Web コンテンツ描画エンジン（WebKit）は、ブラウザ閉鎖中・非アクティブなタブ・URL を持たない空タブでは生成せず、ブラウザ開放中のアクティブ表示または遷移要求の時点で初めてタブ単位に遅延生成する。非アクティブへ移った生成済みタブは表示ツリーから外しつつセッション内へ保持し、アクティブな 1 枚だけを画面へ載せることで描画・レイアウト負担を抑えながらスクロール位置やページ状態を維持する。

- **データストア隔離**: 常用環境かつ DB 利用可能時はプロファイル UUID ごとの永続データストアを使う。隔離環境（`ORBE_STATE_DIR` 設定時、テスト・sandbox 起動）または DB 利用不可時は永続データストアを一切作成・削除せず、プロファイル単位の非永続データストアを共有して分離する。
- **ナビゲーション制限**: メインフレームは HTTP(S) のみを許可し、カスタムスキームや `file:` 等による外部アプリの無確認起動を遮断する。サブフレームは HTTP(S)・`about:`・`data:`・`blob:` のみを許可する。
- **ポップアップとダイアログ**: スクリプトによる自動ポップアップは抑止し、利用者操作由来の新規ウィンドウ要求（`target="_blank"` 等）は、HTTP(S)（非空ホスト）かつメインフレームまたはメインフレームと同一オリジンのサブフレームからの要求のみ同一面で開く。JavaScript の `alert` / `confirm` / `prompt` はモーダルシートを出さず即座にキャンセル応答し、ウィンドウを止めない。
- **WebContent 異常終了**: 描画プロセスが異常終了した場合は読み込み状態を解除し、無限リロードを起こさず `⌘R` または再読込ボタンで復帰できる状態を保つ（未確定時は鍵アイコンなしで要求 URL を保つ）。
