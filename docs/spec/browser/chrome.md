# ブラウザクローム

内蔵ブラウザ層（Z=2 → [core](core.md)）の操作面。ツールバー・サイドバー・ビュー内ポップオーバー・新しいタブ画面・ブラウザ焦点中のキー処理を担う。開発中の端末やエディターから手を離さず、複数スペースとプロファイルの切り替え・タブ整理・URL 遷移を一貫した密度と焦点規律で完結させるための器。

## ツールバーと URL 導線

ブラウザ上端に不透明度 100% の全幅ツールバーを置き、左から サイドバー開閉・戻る・進む・再読込 / 停止・URL 欄・全面めくり案内ピル（全面めくり時のみ）・全面 ⇄ 右シート切替ボタンを並べる。

- **狭幅での縮退**: ツールバーの幅が足りないときは、全面めくり案内ピルを先に省略し、続けて URL 欄を縮小して末尾省略する。サイドバー開閉・戻る・進む・再読込 / 停止・全面 ⇄ 右シート切替の主要 5 ボタンは右シート最小幅や極狭プレビュー幅でも落とさず切らない。
- **操作入口の排他**: ツールバーの全操作入口は、開いているビュー内ポップオーバーを必ず閉じてから動作する。戻る・進む・再読込 / 停止・全面切替は URL 欄の編集も終了してブラウザ本体へ焦点を揃える。サイドバー開閉は URL 欄の編集中も編集状態を維持する。
- **URL 表示**: コミット済みページかつすべてのコンテンツが安全に読み込まれている HTTPS ページでのみ左に鍵アイコンを出し、ホスト部とパス部を 2 トーンの等幅文字で示す（IPv6 リテラルは角括弧付き）。パス部などの可読 UTF-8 文字を維持しつつ、表示反転や切り詰めを起こす Bidi 書式文字・制御文字・行/段落区切りは再パーセントエンコードする。書字方向は左から右（LTR）に固定し、ホストを左・パスを右に保つ。読み込み中は URL 欄の底面に進捗バーを描く。コミット済みページがある間の暫定遷移中は確定まで URL 欄・鍵アイコン・永続 URL を書き換えず、失敗時は元のページ表示を維持する。
- **初回遷移失敗と再試行**: 初回遷移の読み込み中および初回失敗時は、再読込対象が分かるよう要求 URL を鍵アイコンなしで表示し、`⌘R` または再読込ボタンで同じ URL を再試行できる。
- **インライン編集**: URL 欄のクリックで現在の URL を全選択した入力欄へ切り替わる。
  - **明示終了**: Enter で HTTP(S) URL として解決できれば遷移して編集を閉じ、ブラウザ本体へ焦点を戻す。アクティブタブが無い状態での遷移では現在スペースへ新規 `TODAY` タブを自動作成する。URL にならない語句や非 HTTP(S) スキーム（`file:`・`javascript:` 等）は遷移せず編集欄に留まる。スキーム省略時はローカル開発向けホスト（`localhost`・IPv4・`[::1]`・`*.local`・明示ポート付き）へ `http://`、ドットを含む通常ホストへ `https://` を補完する。Esc（IME 変換中でないとき）で取り消してブラウザ本体へ焦点を戻す。
  - **外因終了**: 他所クリック・`⌘B` 閉鎖・ボタン押下・モード変更・表示タブ切替では焦点を奪い返さず編集状態のみ解除する。

## サイドバー

現在のスペースに属するタブ・プロファイル・スペース切替を縦 1 列にまとめる不透明な左パネル。ツールバー左端の開閉ボタンまたは `⌘S` で開閉する。

### モード別開閉記憶と横並び ⇄ 狭幅オーバーレイ

右シートと全面表示では作業幅が異なるため、サイドバーの開閉状態は右シート用と全面用で独立して記憶する（初期値は右シートでは閉・全面では開）。

- **横並び配置**: ブラウザ領域の幅が十分な間は、サイドバーと本文領域（WebView / 新しいタブ画面）を横並びにする。
- **狭幅オーバーレイ配置**: ブラウザ領域が狭い間（狭い右シートや狭幅ウィンドウ）は、本文領域を潰さず全幅のまま保ち、その上に暗幕と右落ち影を伴うオーバーレイドロワーとしてサイドバーを重ねる。
  - 暗幕クリックまたは `Esc` でサイドバーを閉じる。
  - タブをクリックすると選択後にオーバーレイを自動で閉じ、ブラウザ本体へ焦点を戻す。スペース切替時は続けてタブを選べるよう開いたまま保つ。
  - オーバーレイ表示中は下層本文のテキスト欄や WebView へ入力が漏れないよう、本文側の焦点をブラウザ層自身へ退避する。

### 構成と操作

- **ヘッダ**: 左にスペースの印（自由スペースは種別アイコン、ローカルスペースは workspace 名頭文字のバッジ）と表示名（ローカルスペースは現在 workspace 名を参照し、ローカルタグを併記）、右端にプロファイルピル（プロファイル識別色の点・名前・MCP 非公開時の鍵アイコン）を置く。ピルのクリックでプロファイル管理ポップオーバーを開閉する。
- **最上部スロット**: 自由スペースでは `Favorites` タブを 4 列タイルで並べる（0 件時は非表示）。ローカルスペースでは `Favorites` を持たず、ローカル専用の区画用に空けておく。
- **タブ一覧**: `PINNED`（0 件時は見出しごと非表示）→ `TODAY`（見出し右端に `Clear · 12h` 一括整理ボタン）→ `+ 新しいタブ` 行（`⌘T` 表示付き）の順に縦スクロールする。各行のアイコンは外部通信を行わずホスト名（またはタイトル）から決定論的に導くモノグラムチップで描く。誤閉鎖を防ぐためホバー時の閉じるボタンは `TODAY` 行のみに置く。
- **右クリックメニュー**: タブ行・`Favorites` タイルの右クリックから区分移動（`PINNED` / `Favorites` / `TODAY`。ローカルスペースでは `Favorites` への昇格を出さない）とタブ閉鎖を実行できる。下端バーの自由スペースアイコンの右クリックからは編集・削除確認ポップオーバーを開く。
- **下端スペース切替バー**: 左に自由スペース群（横スクロール可、各アイコン右下にプロファイル識別色の点を添える）と新規自由スペース追加ボタン、縦区切り線を挟んで右端に現在 workspace のローカルスペースボタンを置く。

## ビュー内ポップオーバー

プロファイル管理と自由スペースの作成・編集・削除確認は、すべてブラウザ層内部のオーバーレイ層（すりガラスのカード）で完結させる——ウィンドウ外への離脱や画面前面化を構造上起こさず、背後の端末やエディターを止めないため。

- **表示とクランプ**: 同時に開くポップオーバーは 1 つだけとし、カード幅・高さはブラウザ本体領域の内側へ収める（高さが収まらない狭幅・低高ウィンドウでのみカード内を縦スクロールする）。背面余白のクリック（および右クリック・スクロール貫通遮断）や `Esc`、モード切替、フォーカス喪失、ブラウザ閉鎖で閉じる。
- **フォーム切替時の焦点保護**: ポップオーバー内のテキスト入力欄を含む画面から別画面や閉鎖へ移る際は、入力欄の破棄前に焦点をブラウザ層自身へ退避し、ウィンドウへの焦点落下による意図しない連鎖閉鎖を防ぐ。
- **プロファイル管理ポップオーバー**:
  - メイン画面: 現在プロファイルの Cookie 分離説明、MCP 読み取り許可の即座なオン・オフ切替、スペースに割り当てるプロファイル一覧（選択切替・編集ボタン）、新規プロファイル作成導線を並べる。
  - 作成・編集フォーム: 同カード内で切り替え、名前・識別色 6 色・MCP 読み取り許可（新規時の既定は非公開）を編集する。プロファイルが 2 件以上ある編集画面のみ削除導線を置く。
  - 削除確認画面: 対象プロファイルを参照しているスペースがある場合のみ付け替え先プロファイルを選ばせ、確認後に削除を実行する。
- **自由スペースポップオーバー**:
  - 作成・編集フォーム: 名前・アイコン種別（ローカル専用アイコンを除く）・紐づくプロファイルを設定する。新規作成後は新しい自由スペースへ切り替える。
  - 削除確認画面: 編集画面および下端バー右クリックの双方から同じ確認画面へ誘導し、対象スペース名とタブ件数を示したうえで削除する。無確認削除は設けない。

## 新しいタブ画面

アクティブタブが無い、またはアクティブタブに URL が無い間は、WebKit を生成せず不透明度 100% の新しいタブ画面を表示する——起動・新規タブ作成時の WebKit 生成と外部通信をゼロに保つため。

- **構成**: 中央にブランドマークと現在のスペース名・プロファイル名、URL 入力欄、クイックアクセス（現在スペースの `Favorites` と `PINNED` から最大 8 件、0 件時は非表示）、最近閉じたタブ（復元対象の上限 5 件・他スペース由来なら元スペース名と相対時刻を表示、0 件時は非表示）を並べる。
- **URL 入力**: `⌘T` やサイドバーの `+ 新しいタブ` から開いたとき（オーバーレイサイドバー・ポップオーバー閉鎖中）と入力欄クリック時に焦点が当たる。Enter で HTTP(S) URL として解決できれば遷移し、Esc で焦点をブラウザ層へ戻す。URL にならない語句では遷移せず入力欄に留まる。
- **空タブの自動片付け**: 未遷移の `TODAY` 空タブを開いたままクイックアクセスまたは最近閉じたタブを選んで別タブへ移ったときは、元の空タブを履歴へ積まずに自動で閉じる。
- **背景クリック**: 入力欄や一覧以外の余白をクリックすると URL 編集を終了し、ブラウザ層自身へ焦点を移す。通常打鍵は下層へ漏らさず吸収する。

## フォーカスとキー優先順

ブラウザが開いていて焦点がブラウザ層内（本体・URL 入力欄・新タブ入力欄・ポップオーバー）にある間は、窓レベルのタブ不要ショートカットもブラウザ層へ単一経路で降下させ、網羅分類で一括裁定する（→ [chrome/layout](../chrome/layout.md)）。端末・エディター・ボード焦点中は一切介入せず従来の動作を保つ。

| 条件 / キー | ブラウザ本体焦点中 | URL 入力中（ツールバー / 新タブ） | ポップオーバー表示中 | IME 変換中 |
|---|---|---|---|---|
| `⌘B` | ブラウザ閉鎖 | 編集終了＋ブラウザ閉鎖 | ポップオーバー閉鎖＋ブラウザ閉鎖 | IME 優先 |
| `⌘T` | 新しいタブを作成し中央入力欄へ焦点 | 編集終了＋新しいタブを作成 | 無動作消費 | IME 優先 |
| `⌘W` | アクティブが `TODAY` のときのみ閉鎖（`PINNED` / `Favorites` / 0 枚は無動作） | 編集終了＋`TODAY` のみ閉鎖 | 無動作消費 | IME 優先 |
| `⌘R` | ページ再読込 | 無動作消費（編集保護） | 無動作消費 | IME 優先 |
| `⌘⇧T` | 閉じたタブを復元 | 編集終了＋閉じたタブを復元 | 無動作消費 | IME 優先 |
| `⌘S` | サイドバー開閉 | サイドバー開閉（ツールバー編集中は維持） | 無動作消費 | IME 優先 |
| 安全な下層遷移・パレット類（`⌘E`・`⌘⇧F`・`⌘⇧E`・`⌘⇧]` / `[`・`⌘⇧S/A/C/X`・`⌘,`・`⌘H`） | 上位窓コマンドへ転送 | 無動作消費 | 無動作消費 | IME 優先 |
| `⌘⇧←` / `⌘⇧→` | タブ切替として上位転送 | 入力欄へ素通し（行頭・行末選択） | テキスト編集中のみ素通し、以外は無動作消費 | IME 優先 |
| 端末・エディター専用（`⌘+/-/0`・`⌘⇧B`・`⌘P`・`⌘F`） | 無動作消費（背後誤爆防止） | 無動作消費 | 無動作消費 | IME 優先 |
| `⌘↑` / `⌘↓` | Web ページへ素通し | 入力欄へ素通し | 素通し | IME 優先 |
| `Esc` | 狭幅オーバーレイ開なら閉鎖、以外は Web ページへ素通し（空面は吸収） | 編集取消＋ブラウザ本体へ焦点復帰 | ポップオーバー閉鎖＋ブラウザ本体へ焦点復帰 | IME 優先 |

ヘルプ画面（`⌘H`）では、`⌘T`・`⌘W`・`⌘R`・`⌘⇧T`・`⌘S` の各項目に端末・エディター側の動作とブラウザ側の動作を併記する。
