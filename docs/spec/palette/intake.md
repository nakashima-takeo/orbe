# 受信タブ

[受信](../platform/intake.md)が裏で置いた提案を、人がタスクにするか捨てるかを決める場所。[タスク画面](tasks.md)（⌘⇧X）のヘッダーの「受信 N」で開く（クリックか ⇧⇥）。提案をさばく口は人のためのもので、AI には出さない。受信を足す・変えるのは秘書（AI）の仕事で、この画面では定義を書き換えない——棚の下にも「受信を足す・変えるのは秘書に頼む」と出す。

画面は受信のストアと走らせ役を直接読み、値を写さない。持つのは棚と提案の一覧の選択（同一性）・入力・居場所・失敗だけ。だから裏の回が確定したり AI が受信を変えたり消したりすると、棚・提案・中身はすぐ追従する。タスクのタブ・GitHub タブとは「タスクにする」でタスクのストアに書くことしか共有しない。

## 3 列

カードの大きさの上限はタスク画面と同じ。棚はカードの幅の 1/4（狭い窓では下限で止める）、詳細は他のタブの右の欄と同じ幅で、残りを真ん中に配る。

- **棚（左）**: 先頭に「すべて N」、続いて受信を ID 順に、名前・件数・2 行目を出す。件数は棚に出ている人の判断待ちの提案の数（棚に出す受信の決め方は[受信](../platform/intake.md#棚と重なり)）。
  - 2 行目は「次 17:00」（今日でなければ日付付き）。止めていれば「止めている」、走っていれば「受信中…」（強調色）。
  - 提案の無い受信は名前を減光し、2 行目に「· 提案なし」を足す。前回の回が失敗していれば「· 前回は失敗」（赤）を足す。色だけに意味を載せず、どれも文字で言う。
  - 印はどの受信も共通の 1 つ。Orbe は出どころの種類を知らないので、名前から出どころを推して見せ方を変えない。
- **提案の一覧（真ん中）**: 棚の選択で絞った人の判断待ちの提案。提案した回の新しい順で、同じ回の中は判定の出力順。
  - 受信を選んでいれば、頭に前回の回「13:00 の回 · 9 件取得 → 新しい 4 件を判定 → 提案 2」と「中身 →」を出す。新しい項目が無かった回は「… → 新しい項目なし」、失敗した回は「13:00 の回 · 失敗 — <理由>」（赤）、まだ回っていなければ「まだ回っていない」。狭い欄では 2 行まで折り返す。
  - 行はタイトル・期限の札（「10/10 金」）・右に項目の時刻（今日なら時刻、ほかの日は日付）、下に本文の先頭 1 行。
  - 提案が無ければ「提案はありません」。
- **詳細（右）**: 選んでいる提案の「<受信名> · 今日 10:24」、本文の全体（引用の箱）と「↗ <ホスト名> で開く」、「タスクにすると」のタイトルと「期限 10/10（金）」（期限が無ければ出さない）、「↵ タスクにする」「⌘⌫ 捨てる」のボタン。リンクはホスト名で言う（出どころの種類で言い換えない）。

入力欄に打つと、タイトルか本文に一致する提案だけに絞る（大文字小文字・濁点などを区別しない）。

## さばく

- **↵**（かボタン）: 提案のタイトルと期限を引き継いだ未着手のタスクを、Home に付けて、入力欄から足したタスクと同じくその優先度の未着手の先頭に足す（詳細欄にリンクと本文）。提案は棚から消え、同じ位置の行が選ばれる。タスクのタブの件数が 1 増える。付ける Home は画面を開いた時点のもの（⌘⇧X の workspace の扱いと同じ）。タスクのストアが拒んだときだけ、フッターに赤で「タスクにできませんでした」。
- **⌘⌫**（入力欄が空のとき。かボタン）: 提案を捨てる。タスクはできない。入力欄に文字があるときの ⌘⌫ は行頭まで消すだけ。
- **⌘↵** かリンクのクリック: 提案のリンクをブラウザで開く。

捨てるのは単キー（x など）ではなく ⌘⌫ にしている。提案の一覧では焦点が絞り込み欄にあるので、単キーにすると絞り込みのつもりで打った 1 文字で提案が消える。捨てた提案は戻せず、そのリンクは二度と提案されない。タスクのタブの「取り消せない操作は ⌘⌫（入力欄が空のときだけ）」に揃えた。x は文字として絞り込み欄に入る。

選んでいた提案が、押す前に判定の確定や別の口でさばかれていたら、何もせず赤も出さない（付け直しが次の行へ移す）。

## 居場所とキー

居場所は 3 つで、→ が一段深く、← が一段浅い（棚 ← 提案の一覧 → 中身）。開いた直後は「すべて」・提案の一覧に居る。タブを行き来しても、棚と提案の選択・入力・居場所は残る（開き直すと初めから）。

| 居場所 | キー | 動き |
|---|---|---|
| 提案の一覧 | ↑↓ / ⌘↑↓ | 提案の選択（端で巡回 / 先頭・末尾） |
| | ↵ | タスクにする |
| | ⌘⌫ | 入力欄が空なら捨てる。文字があれば行頭まで消す |
| | ⌘↵ | リンクをブラウザで開く |
| | → | 受信を選んでいれば中身へ（文字の有無を問わない） |
| | ← | 入力欄が空なら棚へ（文字があれば文字の間を動く） |
| | ⇧⇥ / esc | 次のタブ / 閉じる |
| 棚 | ↑↓ / ⌘↑↓ | 棚の選択。真ん中と右がそれに追従し、提案は先頭が選ばれる |
| | → / ↵ / esc | 提案の一覧へ |
| 中身 | ↵ | 今すぐ受信 |
| | space | 止める ⇄ 再開 |
| | ⌘⌫ | 確認なしで受信を消し、提案の一覧へ戻る（棚は同じ位置の段を選ぶ） |
| | ← / esc | 提案の一覧へ |

- 棚と中身ではカードの器が焦点を持ち、⇥・⇧⇥ は握るだけでタブを替えない（他のタブの右の欄と同じ）。入力欄のクリックで提案の一覧へ戻る。
- 捨てる・削除・今すぐ受信・止める・ブラウザで開くは押した瞬間だけを操作にし、押し続けたキーリピートは捨てる（行頭まで消して空になった瞬間のリピートで提案を捨てない）。
- 「すべて」では → は効かず、「中身 →」も出ない。中身は受信 1 つのもの。
- 受信の削除に確認を挟まないのは、タスクの ⌘⌫ に揃えたため。消した受信の定義は、秘書に作り直してもらう。
- マウス: 棚の段のクリックで選んで提案の一覧に居る。提案の行のクリックで選ぶ。「中身 →」のクリックで中身へ。ホバーの選択追従は、その一覧に居る間だけ、他のパレットと同じ入力モダリティの規約で効く。
- フッターの左は居場所と選択で主な操作を 1 行で言い（「↵ <タイトル> をタスクにする」「↵ <受信名> を今すぐ受信」）、失敗は赤で置き換える。右はその場所で効くキー。⌘↵ はタスクのタブと意味が違うので、提案の一覧ではヒントに「⌘↵ ブラウザで開く」を出す。

## 受信の中身

真ん中と右をまたいで 1 枚で出す。

- 名前と状態（次の時刻 / 止めている / 受信中…）。
- **取得**: やり方（軽い agent なら CLI・モデル・使えるツール・依頼文、コマンドなら実行するコマンド・作業ディレクトリ）と、いつ（「30 分ごと」「毎日 9:00・13:00」）。
- **判定**: CLI・モデル・指示文。
- **前回**: 「今日 9:12 · 14 件取得 → 新しい 3 件を判定 → 1 件を提案」。失敗なら理由（赤）。回の記録の一覧は出さない（AI が `list_intakes` で読む）。
- **重なり**: 前回の取得結果のリンクが重なっている相手の受信と件数（無ければ出さない）。
- 「名前・取得・判定は秘書が一度にまとめて書き換える」と、操作のボタン（今すぐ受信・止める ⇄ 再開・削除）。

## 受信中

走っているかは[番人](../platform/background.md#番人)が持ち、画面はそれを観測して描く（写しを持たない）。今すぐ受信から判定の終わりまでは数分かかることがあり、出さないと押しても何も起きていないように見えるため、棚と中身に「受信中…」を出す。回が終わると、前回の表示が新しい回に替わる。走っている間の ↵ は断り、フッターに赤で「受信中のため今すぐ受信できません」を出す。

## 追従

選んでいる提案と受信は同一性で持つ。裏の回の確定・AI の変更・削除で行が変わるたびに付け直し、同一性が今の行にあればそのまま、無ければ最後に居た位置（末尾で頭打ち）の行へ移す。中身を見ている受信が消えたら（棚の選択が別の段へ移ったら）、提案の一覧へ戻る。
