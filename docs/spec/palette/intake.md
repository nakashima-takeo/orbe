# 自動追加タブ

[タスクの自動追加](../platform/intake.md)が裏で置いた候補を、人がタスクにするか捨てるかを決める場所。[タスク画面](tasks.md)（⌘⇧X）のヘッダーの「自動追加 N」で開く（クリックか ⇧⇥）。候補をさばく口は人のためのもので、AI には出さない。自動追加を足す・変えるのは秘書（AI）の仕事で、この画面では定義を書き換えない——棚の下にも「自動追加を足す・変えるのは秘書に頼む」と出す。

画面は自動追加のストアと走らせ役を直接読み、値を写さない。持つのは棚と候補の一覧の選択（同一性）・入力・居場所・失敗だけ。だから裏の回が確定したり AI が自動追加を変えたり消したりすると、棚・候補・中身はすぐ追従する。タスクのタブ・GitHub タブとは「タスクにする」でタスクのストアに書くことしか共有しない。

## 3 列

カードの大きさの上限はタスク画面と同じ。棚はカードの幅の 1/4（狭い窓では下限で止める）、詳細は他のタブの右の欄と同じ幅で、残りを真ん中に配る。

- **棚（左）**: 先頭に「すべて N」、続いて自動追加を ID 順に、名前・件数・2 行目を出す。件数は棚に出ている人の判断待ちの候補の数（棚に出す自動追加の決め方は[タスクの自動追加](../platform/intake.md#棚と重なり)）。
  - 2 行目は「次 17:00」（今日でなければ日付付き）。止めていれば「止めている」、走っていれば「実行中…」（強調色）。
  - 候補の無い自動追加は名前を減光し、2 行目に「· 候補なし」を足す。前回の回が失敗していれば「· 前回は失敗」（赤）を足す。色だけに意味を載せず、どれも文字で言う。
  - 印はどの自動追加も共通の 1 つ。Orbe は出どころの種類を知らないので、名前から出どころを推して見せ方を変えない。
- **候補の一覧（真ん中）**: 棚の選択で絞った人の判断待ちの候補。候補を出した回の新しい順で、同じ回の中は判定の出力順。
  - 自動追加を選んでいれば、頭に前回の回「13:00 の回 · 9 件取得 → 新しい 4 件を判定 → 候補 2」と「中身 →」を出す。新しい項目が無かった回は「… → 新しい項目なし」、失敗した回は「13:00 の回 · 失敗 — <理由>」（赤）、まだ回っていなければ「まだ回っていない」。狭い欄では 2 行まで折り返す。
  - 行はタイトル・期限の札（「10/10 金」）・右に項目の時刻（今日なら時刻、ほかの日は日付）、下に本文の先頭 1 行。
  - 候補が無ければ「候補はありません」。
- **詳細（右）**: 選んでいる候補の「<自動追加の名前> · 今日 10:24」、本文の全体（引用の箱）と「↗ <ホスト名> で開く」、「タスクにすると」のタイトルと「期限 10/10（金）」（期限が無ければ出さない）、「↵ タスクにする」「⌘⌫ 捨てる」のボタン。リンクはホスト名で言う（出どころの種類で言い換えない）。

入力欄に打つと、タイトルか本文に一致する候補だけに絞る（大文字小文字・濁点などを区別しない）。

## さばく

- **↵**（かボタン）: 候補のタイトルと期限を引き継いだ未着手のタスクを、Home に付けて、入力欄から足したタスクと同じ規則の位置（Home の欄で——範囲が「すべて」なら全体で——その優先度の未着手の先頭）に足す（詳細欄にリンクと本文）。候補は棚から消え、同じ位置の行が選ばれる。タスクのストアが拒んだときだけ、フッターに赤で「タスクにできませんでした」。
- **⌘⌫**（入力欄が空のとき。かボタン）: 候補を捨てる。タスクはできない。入力欄に文字があるときの ⌘⌫ は行頭まで消すだけ。
- **⌘↵** かリンクのクリック: 候補のリンクをブラウザで開く。

捨てるのは単キー（x など）ではなく ⌘⌫ にしている。候補の一覧では焦点が絞り込み欄にあるので、単キーにすると絞り込みのつもりで打った 1 文字で候補が消える。捨てた候補は戻せず、そのリンクは二度と候補にならない。タスクのタブの「取り消せない操作は ⌘⌫（入力欄が空のときだけ）」に揃えた。x は文字として絞り込み欄に入る。

選んでいた候補が、押す前に判定の確定や別の口でさばかれていたら、何もせず赤も出さない（付け直しが次の行へ移す）。

## 居場所とキー

居場所は 3 つで、→ が一段深く、← が一段浅い（棚 ← 候補の一覧 → 中身）。開いた直後は「すべて」・候補の一覧に居る。タブを行き来しても、棚と候補の選択・入力・居場所は残る（開き直すと初めから）。

| 居場所 | キー | 動き |
|---|---|---|
| 候補の一覧 | ↑↓ / ⌘↑↓ | 候補の選択（端で巡回 / 先頭・末尾） |
| | ↵ | タスクにする |
| | ⌘⌫ | 入力欄が空なら捨てる。文字があれば行頭まで消す |
| | ⌘↵ | リンクをブラウザで開く |
| | → | 自動追加を選んでいれば中身へ（文字の有無を問わない） |
| | ← | 入力欄が空なら棚へ（文字があれば文字の間を動く） |
| | ⇧⇥ / esc | 次のタブ / 閉じる |
| 棚 | ↑↓ / ⌘↑↓ | 棚の選択。真ん中と右がそれに追従し、候補は先頭が選ばれる |
| | → / ↵ / esc | 候補の一覧へ |
| 中身 | ↵（修飾なし） | 今すぐ実行 |
| | space | 止める ⇄ 再開 |
| | ⌘⌫ | 確認なしで自動追加を消し、候補の一覧へ戻る（棚は同じ位置の段を選ぶ） |
| | ← / esc | 候補の一覧へ |

- 棚と中身ではカードの器が焦点を持ち、⇥・⇧⇥ は握るだけでタブを替えない（他のタブの右の欄と同じ）。入力欄のクリックで候補の一覧へ戻る。
- 中身の操作（今すぐ実行・止める ⇄ 再開・削除）は、キー・キーの表示・名前・走っている間の断りまで[ボード](../chrome/board.md#自動追加の部品)の自動追加と同じ 1 つの定義を使う。画面ごとにキーと表示が食い違わないため。⌘↵・⇧↵ は中身では何もしない。
- 捨てる・削除・今すぐ実行・止める・ブラウザで開くは押した瞬間だけを操作にし、押し続けたキーリピートは捨てる（行頭まで消して空になった瞬間のリピートで候補を捨てない）。
- 「すべて」では → は効かず、「中身 →」も出ない。中身は自動追加 1 つのもの。
- 自動追加の削除に確認を挟まないのは、タスクの ⌘⌫ に揃えたため。消した自動追加の定義は、秘書に作り直してもらう。
- マウス: 棚の段のクリックで選んで候補の一覧に居る。候補の行のクリックで選ぶ。「中身 →」のクリックで中身へ。ホバーの選択追従は、その一覧に居る間だけ、他のパレットと同じ入力モダリティの規約で効く。
- フッターの左は居場所と選択で主な操作を 1 行で言い（「↵ <タイトル> をタスクにする」「↵ <自動追加の名前> を今すぐ実行」）、失敗は赤で置き換える（赤は自動追加タブの次の操作か、タブを替える操作で消える）。右はその場所で効くキー。⌘↵ はタスクのタブと意味が違うので、候補の一覧ではヒントに「⌘↵ ブラウザで開く」を出す。

## 自動追加の中身

真ん中と右をまたいで 1 枚で出す。

- 名前と状態（次の時刻 / 止めている / 実行中…）。
- **取得**: やり方（軽い agent なら CLI・モデル・使えるツール・依頼文、コマンドなら実行するコマンド・作業ディレクトリ）、性質とそれで候補がいつ下がるか（「今の集合 · 取得から消えた候補を下げる」「新着の流れ · 判定が対応済みとした候補だけを下げる」）、いつ（「30 分ごと」「毎日 9:00・13:00」）。
- **判定**: CLI・モデル・指示文。
- 取得と判定の中身（使えるツール・依頼文・コマンド・作業ディレクトリ・指示文）は行数で切らず、折り返して全文を出す——承認なしで裏で走るものを、画面でいつも確かめられるため。
- **前回**: 「今日 9:12 · 14 件取得 → 新しい 3 件を判定 → 候補 1 件」。失敗なら理由（赤）。回の記録の一覧はここでは出さない（[ボード](../chrome/board.md#自動追加の部品)の詳細で読める。AI は `list_intakes` で読む）。
- **重なり**: 前回の取得結果のリンクが重なっている相手の自動追加と件数（無ければ出さない）。
- 「名前・取得・判定は秘書が一度にまとめて書き換える」と、操作のボタン（今すぐ実行・止める ⇄ 再開・削除）。

## 実行中

走っているかは[番人](../platform/background.md#番人)が持ち、画面はそれを観測して描く（写しを持たない）。今すぐ実行から判定の終わりまでは数分かかることがあり、出さないと押しても何も起きていないように見えるため、棚と中身に「実行中…」を出す。回が終わると、前回の表示が新しい回に替わる。走っている間の ↵ は断り、フッターに赤で「実行中のため今すぐ実行できません」を出す。

## 追従

選んでいる候補と自動追加は同一性で持つ。裏の回の確定・AI の変更・削除で行が変わるたびに付け直し、同一性が今の行にあればそのまま、無ければ最後に居た位置（末尾で頭打ち）の行へ移す。中身を見ている自動追加が消えたら（棚の選択が別の段へ移ったら）、候補の一覧へ戻る。
