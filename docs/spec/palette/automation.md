# 提案タブ

[タスクの自動追加](../platform/automation.md)が裏で置いた候補を、人がタスクにするか捨てるかを決める場所。[タスク画面](tasks.md)（⌘⇧X）のヘッダーの「提案 N」で開く（クリックか ⇥ / ⇧⇥）。候補をさばく口は人のためのもので、AI には出さない。自動追加を足す・変えるのは Home の[ボード](../chrome/board.md#自動化の部品)から頼む（頼みを受けた agent が書き換える）。この画面では定義を書き換えない——棚の下にも「自動追加を足す・変えるのは Home のボードから頼む」と出す。

画面は自動追加のストアと走らせ役を直接読み、値を写さない。持つのは棚と候補の一覧の選択（同一性）・入力・居場所・失敗だけ。だから裏の回が確定したり AI が自動追加を変えたり消したりすると、棚と候補はすぐ追従する。タスクのタブ・GitHub タブと共有する値は、「タスクにする」で書くタスクのストアだけ。

## 3 列

カードの大きさの上限はタスク画面と同じ。棚はカードの幅の 1/4（狭い窓では下限で止める）、詳細は他のタブの右の欄と同じ幅で、残りを真ん中に配る。

- **棚（左）**: 先頭に「すべて N」、続いて判定の部品を持つ自動追加を ID 順に、名前・件数・2 行目を出す（判定の部品を持たない自動化は候補を出さないので並べない）。件数は棚に出ている人の判断待ちの候補の数（棚に出す自動追加の決め方は[タスクの自動追加](../platform/automation.md#棚と重なり)）。
  - 2 行目は次の判定がいつか。判定の部品の予定を、時刻のある判定（複数なら最も早い時刻）「次の判定 10/5 9:00」（今日なら「次の判定 9:00」）→「届いたら」の判定「新着が届くたびに判定」→ 手動の判定「判定は手動（⌘↵ で更新）」の順で、最初に当たったもので言う——次に候補が来うる時を、言える中で最も具体的に言うため。止めていれば「停止中」。
  - 候補を更新している一巡の間は、2 行目を「更新中…」（強調色）だけにする。一巡は走らせ役のメモリにあるものを直接読むので、ボードの ↵ や `run_automation` で始めた一巡でも出る。予定どおりの回が走っているだけでは何も出さない。
  - 候補の無い自動追加は名前を減光し、2 行目に「· 候補なし」を足す。最後の回が失敗した部品があれば「· 判定: 連絡 で失敗」（赤）を足す。数えるのは自動化の全部品で、複数なら新しい失敗を先に「判定: 連絡 ほか 1 件 で失敗」。言い方はボードの一覧の右端と同じ。色だけに意味を載せず、どれも文字で言う。
  - 時刻は開いた時点で描き、分の境では描き直さない。
  - 選んでいる段の地は、焦点が棚にある間は普段の選択の地、絞り込み欄か候補の一覧にある間は薄い地（選んでいるが、キーが届く場所ではない）。焦点の場所を地で見分けるため。
  - 印はどの自動追加も共通の 1 つ。Orbe は出どころの種類を知らないので、名前から出どころを推して見せ方を変えない。
- **候補の一覧（真ん中）**: 棚の選択で絞った人の判断待ちの候補。候補を出した回の新しい順で、同じ回の中は判定の出力順。
  - 自動追加を選んでいれば、頭に判定の部品ごとの最新の回を入力の深さ順に 1 行ずつ出す（「9:00 判定: 開発 · 12 件 → 候補 2」）。失敗した回は「13:00 判定: 連絡 · 失敗 — <理由>」（赤）、まだ回っていなければ「判定: 開発 · まだ回っていない」。各行は狭い欄で 2 行まで折り返す。部品は「役割: 名前」で言う。
  - 行はタイトル・期限の札（「10/10 金」）・右に項目の時刻（今日なら時刻、ほかの日は日付）、下に出どころの取得の部品の名前と本文の先頭 1 行（「GitHub · <本文の先頭 1 行>」）。部品の名前は候補を出した自動化の定義から引くので、棚の自動化と別の自動化の部品名が並ぶことがある。部品か自動化が消えていて引けなければ本文だけ。
  - 印（選択の地）は選ばれている候補の行にだけ出す。
  - 候補が無ければ「候補はありません」。
- **詳細（右）**: 選ばれている候補の「<棚の自動追加の名前> · <取得の部品の名前> · 今日 10:24」（部品の名前を引けなければ省く）、本文の全体（引用の箱）と「↗ <ホスト名> で開く」、「タスクにすると」のタイトルと「期限 10/10（金）」（期限が無ければ出さない）と「workspace <付け先の名前>」、「↵ タスクにする」「⌘↵ タスクにして開く」「⌘⌫ 捨てる」のボタン。選ばれている候補が無ければ空。リンクはホスト名で言う（出どころの種類で言い換えない）。付け先は Home のときも出し、↵ の前に行き先が分かるようにする。名前は描くときの今の workspace で解く（画面は workspace の改名・削除を観測しないので、描き直すまで前の名前が残りうるが、↵ は押した時点の値で付け先を解く）。

入力欄に打つと、タイトルか本文に一致する候補だけに絞る（大文字小文字・濁点などを区別しない）。

## さばく

- **↵**（かボタン）: 候補のタイトルと期限を引き継いだ未着手のタスクを、付け先に付けて足す（詳細欄にリンクと本文）。付け先は候補の付け先の workspace が今もあればそれ、無ければ Home（→ [候補をタスクにする](../platform/automation.md#候補をタスクにする)）。候補は棚から消え、同じ位置の行が選ばれる。タスクのストアが拒んだときだけ、フッターに赤で「タスクにできませんでした」。
- **⌘↵**（かボタン）: ↵ と同じくタスクにしてから、そのタスクの agent を開く（タスクのタブの ⌘↵ と同じ口）。できたばかりのタスクには続きから始める会話が無いので、⌘⇧X を閉じ、そのタスクのための [⌘T](worktree.md#タスクから開く) を開く。⌘T は付け先の workspace に結び付き、Home なら Home のタスクの作業場の 1 行になり、↵ でそこに agent が開く。リポジトリで作業したいときは、⌘T の札を外して開いた workspace のリポジトリを選ぶ（その場合、タスクとは結び付かない）。タスクにできなければ ⌘T は開かず、↵ と同じ赤を出す。
- **⌘⌫**（入力欄が空のとき。かボタン）: 候補を捨てる。タスクはできない。入力欄に文字があるときの ⌘⌫ は行頭まで消すだけ。
- **⌘O** かリンクのクリック: 候補のリンクをブラウザで開く。タスクはできない。

捨てるのは単キー（x など）ではなく ⌘⌫ にしている。候補の一覧では焦点が絞り込み欄にあるので、単キーにすると絞り込みのつもりで打った 1 文字で候補が消える。捨てた候補は戻せず、そのリンクは二度と候補にならない。タスクのタブの「取り消せない操作は ⌘⌫（入力欄が空のときだけ）」に揃えた。x は文字として絞り込み欄に入る。

さばく操作はどれも選ばれている候補にだけ効く。絞り込み欄と棚に居る間は候補が選ばれていないので、↵・⌘↵・⌘⌫・⌘O は候補に何もしない——印の無い行を誤ってタスクにしたり捨てたりしないため。

選んでいた候補が、押す前に判定の確定や別の口でさばかれていたら、何もせず赤も出さない（付け直しが次の行へ移す）。

## 居場所とキー

居場所は 3 つ: 絞り込み欄・棚・候補の一覧。開いた直後は絞り込み欄に居て、打てばすぐ絞り込める。候補の一覧は覚えている行（初めは先頭。棚の段を替えたらその段の先頭。入力が変わったら先頭）を持ち、それが「選ばれている」のは一覧に居る間だけ。タブを行き来しても、居場所・棚の選択・覚えている行・入力は残る（開き直すと初めから）。

| 居場所 | キー | 動き |
|---|---|---|
| 絞り込み欄 | 文字 | 絞り込む（選ばれてはいない） |
| | ↓ / ←（入力欄が空のとき） | 棚へ |
| | ↑ / ⌘↑↓ | 何もしない |
| | → / 文字があるときの ← | 入力欄の文字の間を動く |
| | ↵ / ⌘↵ / ⌘⌫ / ⌘O | 候補には効かない（⌘⌫ は文字があれば行頭まで消す） |
| | esc | 閉じる |
| 棚 | ↑↓ / ⌘↑↓ | 棚の選択（端で巡回しない / 先頭・末尾）。先頭の ↑ は絞り込み欄へ。段を替えると覚えている行はその段の先頭 |
| | ↵ / → | 候補の一覧へ（覚えている行が選ばれる） |
| | ⌘↵ | 自動追加の段: その候補を今すぐ更新。「すべて」: 何もしない |
| | esc | 閉じる |
| 候補の一覧 | 文字 | 絞り込み、一覧に留まって先頭が選ばれる |
| | ↑↓ / ⌘↑↓ | 候補の選択（端で巡回 / 先頭・末尾） |
| | ↵ | タスクにする |
| | ⌘⌫ | 入力欄が空なら捨てる。文字があれば行頭まで消す |
| | ⌘↵ | タスクにして ⌘T を開く |
| | ⌘O | リンクをブラウザで開く |
| | ←（入力欄が空のとき） | 棚へ |
| | → | 何もしない（文字があれば文字の間を動く） |
| | esc | 閉じる |

⇥ / ⇧⇥ はどの居場所でも次 / 前のタブ（タスク画面のどこでも同じ）。

- 絞り込み欄と候補の一覧は入力欄が焦点を持ち、棚はカードの器が焦点を持つ。棚で文字を打っても何も起きない（打った文字を入力欄へ渡すと日本語入力の変換を通らないため）。絞り込むには棚の先頭の ↑ か入力欄のクリックで絞り込み欄へ戻る。
- 棚が端で巡回しないのは、先頭の ↑ を絞り込み欄へ戻る道にするため（↓ で欄から下りた道を ↑ で戻れる）。
- esc はどの居場所でも閉じる。居場所を戻るのは ← と ↑ が持つ。
- 押し続けたキーリピートは押し始めた焦点の宛先でだけ効く（[タスク画面](tasks.md#一覧のキー)と同じ）。棚で ↵ を押し続けても一覧で止まってタスクにしない。
- 捨てる・タスクにして開く・ブラウザで開く・候補の更新は押した瞬間だけを操作にし、押し続けたキーリピートは捨てる（行頭まで消して空になった瞬間のリピートで候補を捨てない）。⌘↵ を押し続けても、タスクは 1 つしかできず、開いた ⌘T の ↵ はリピートでは確定しないので、行を選ぶ前に agent が開くことはない。
- マウス: 棚の段のクリックでその段を選んで棚に居る（焦点のある列だけが選ばれているので、候補は選ばれず、⌘↵ はその自動追加の候補の更新になる）。候補の行のクリックでその行を選んで一覧に入る。棚に居る間の入力欄のクリックで絞り込み欄へ（一覧からなら一覧のまま）。ホバーの選択追従は、その一覧に居る間だけ、他のパレットと同じ入力モダリティの規約で効く。
- フッターの左は居場所と選択で主な操作を 1 行で言い（棚の自動追加の段「⌘↵ <自動追加の名前> の候補を今すぐ更新」、棚の「すべて」「→ 候補の一覧へ」、一覧「↵ <タイトル> をタスクにする」。絞り込み欄では出さない）、失敗は赤で置き換える（赤は提案タブの次の操作か、タブを替える操作で消える）。右はその場所で効くキー: 絞り込み欄「↓ 棚へ」「⇥ タブ」「esc 閉じる」、棚「↑↓ 自動追加」「→ 候補へ」「⇥ タブ」「esc 閉じる」、一覧（候補を選んでいる間）「⌘↵ タスクにして開く」「⌘⌫ 捨てる」「⌘O ブラウザで開く」と「← 棚へ」「⇥ タブ」「esc 閉じる」。

## 候補の今すぐ更新

棚で自動追加を選んで ⌘↵ を押すと、その自動追加のタスク候補を行き先にする部品（判定）すべてまで[流す](../platform/automation.md#止める流す)——判定へ至る取得が今すぐ走り、終わり次第判定も走る。一巡の間は棚の行が「更新中…」になり、終われば新しい候補が一覧に出る。今すぐ実行・停止 ⇄ 再開・削除はこの画面では扱わず、Home の[ボード](../chrome/board.md#自動化の部品)で行う。

- 一巡の途中の ⌘↵ は断り、フッターに赤で「更新中のため、今は更新できません」を出す。「更新中…」は一巡がある間ずっと出るので、表示と断りが一致する。
- 行き違い（押す前に自動追加が消えていた・自動化の DB を使えない）は黙る。
- 判定の部品が無くなっていれば何も起きない。

## 追従

選んでいる候補と自動追加は同一性で持つ。裏の回の確定・AI の変更・削除で行が変わるたびに付け直し、同一性が今の行にあればそのまま、無ければ最後に居た位置（末尾で頭打ち）の行へ移す。
