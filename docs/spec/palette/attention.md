# Attention パレット

対応すべきエージェントを 1 枚で見て、選んでそのペインへ飛ぶための面。全 workspace を横断し、エージェント状態（[agent/notify](../agent/notify.md)）の**単一情報源**を読む。同じ情報源をメニューバー投影（[menubar](../chrome/menubar.md)）も読み、両者は常に同じ値を出す。文言は現在言語に追従する（[localization](../platform/localization.md)）。

## 入口

- **⌘⌘（Command 素タップ×2）**: Orbe が前面のとき開閉トグルする。他パレット表示中は差し替え（既存パレット同士の遷移規約 → [layout](../chrome/layout.md)）。真のモーダル（言語選択・オンボーディング・更新内容）とヘルプ（[help](../chrome/help.md)）の表示中は no-op——ヘルプはショートカットを試し押しして確かめる場で、そこに ⌘⌘ が載る以上必ず試されるため、効くとヘルプ自体が消えてしまう。
- **TopBar 右端の件数ストリップのクリック**（[chrome](../chrome/chrome.md)）。ジェスチャは画面に書けないので、可視の入口を対で持つ。
- Orbe が**背面**のときの ⌘⌘ は、このパレットではなくメニューバーのドロップダウンを開く（→ [menubar](../chrome/menubar.md)。権限規律もそちら）。

**素タップの判定**: 「修飾なし → ⌘ のみ → 修飾なし」の遷移で、押下↔解放の間に他のキー・マウス・他修飾が挟まらないもの。2 回の**解放同士**の間隔が上限以内で、**2 回目の解放で**発火する——⌘ は常に何かの前置になり得るので、解放まで待たないと単独ジェスチャかコンビネーションの前置かが確定しない。⌘ の長押しは素タップ性を壊さない（間隔は解放同士で測るため）。他修飾が見えたら全修飾が解放されるまで判定を再開しない（⌘C→⌘V の速い連打で誤発火しない）。

## 一覧

対象は **activate 済み workspace のライブペインのみ**（休眠 workspace は対象外）で、エージェント状態が `waiting` / `done` / `working` のペイン。`idle` と未報告は出さない。並びは**状態変化時刻の降順**（同時刻はペイン ID 降順で安定化）で、セクション・グルーピングを持たない——`waiting` と `done` は同格で、状態の差はグリフだけが語る。

行は 2 段。

- 上段: 状態グリフ・ワークスペース名・`›`・タブタイトル（省略）・右端に経過時間。
- 下段（文言があるときだけ）: hook 由来の文言を 3 行で打ち切る（全文はペインで読む）。`waiting` は強調色、`done` は減光。

`working` は**文言を持たない**——ライブ進行を報告する配管が無く、持たせれば古い依頼文が残るため。経過時間は表示中 1 秒周期で自走する。行が 1 つも無ければ情報行 1 本を出す。

**表示中の追従**: 一覧はエージェント状態の変化で開いたまま更新される。並びが変化時刻順である以上、開いている間に別ペインが変われば行は先頭に挿し込まれて以降がずれるので、**選択はペイン ID を錨に追い直す**——index を据え置くと ↵ が選んだ覚えのない別ペインを前面化し、そのまま打鍵すれば別のエージェントへ入力が入ってしまう。錨が一覧から消えたときだけ範囲へ丸める。裏の更新はユーザーの意図ではないので、入力モダリティ（[workspace パレット](workspace.md)）は奪わない。

## 操作

フィルタ入力欄・ドリルインは持たない——開いて選んで飛ぶだけの面。

- **↑↓** 1 行移動・**⌘↑↓** 先頭/末尾ジャンプ（共有 `PaletteCard` の規律 → [workspace パレット](workspace.md)）。ホバーで選択が追従し、行タップは ↵ と同じ決定。
- **↵ / 行タップ**: そのペインへ移動する（workspace の activate ＋タブ選択＋ペイン focus。制御 API の focus と同一経路 → [control/api](../control/api.md)）。移動したらパレットを閉じる。`done` の行へ移動すれば、見ているタブに `done` を残さない既存規律（[chrome](../chrome/chrome.md)）がそのまま効いて一覧からも消える。
- **esc / 暗幕タップ**: 閉じる。

ヘッダは breadcrumb「attention」＋右端に `⌘⌘` バッジ。フッターは `↵ そのペインへ移動` / `↑↓ 選択` / `esc 閉じる`。
