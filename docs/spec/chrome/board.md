# ボード

ボードは、workspace がタブの並びとは別に持つ 1 枚の面。端末の代わりに content を占めるが、タブではない——端末 surface を持たず、閉じられず、並びの中で動かない。今ボードを持つのは [Home](../platform/workspace.md#home) だけで、中身は[タスクの自動追加](../platform/intake.md)の部品 1 つ。

タブの並びの外に置くのは、タブの並びが「端末 surface 1 枚」を前提に、制御 API・Attention・保存・秘書の判定から広く読まれているため。ボードを混ぜると、それらすべてに例外が要る。どの workspace がボードを持つかは store の 1 つの判定が決め、workspace 自身は知らない。

## タブ行での位置と見え方

ボードを持つ workspace では、タブ行（[chrome](chrome.md)）の左端、横スクロール領域の外にボードのセルが固定される。セルは単独タブの器（無彩色の地・小さな角丸）に家のグリフと workspace 名を載せ、右に細い区切り線を置く。選択中はタブと同じく前景色を反転する。ラベルは workspace 名なので、Home を改名すれば追随する。

スクロール領域の外にあるので、タブが多くて横スクロールしてもセルは左端に残り、タブの幅の配分・並び替えのドラッグの幾何にも入らない。セルの幅は、タブに配る利用可能幅から先に引く。

## 選び方と巡回

セルのクリックでボードを選ぶ。⌘⇧] / ⌘⇧[（⌘⇧→ / ⌘⇧← も同じ）は「ボード → タブ 1 … タブ n → ボード」を 1 つの環として回る。ボードを選んでいる間もこのキーで巡回できる。タブが 0 枚なら、巡回してもボードのまま。

workspace の選択は「何も無い／ボード／どのタブか」の 1 つの値で、タブは位置ではなくタブそのものを指す。並び替え・連の再編・タブの追加で並びが変わっても、同じタブを指し続ける。

## 消えない・動かない

ボードは閉じる操作を受けない。セルには中クリック・右クリックのメニュー・ドラッグを付けていない。タブをボードの左へ落とすこともできない（並び替えはスクロール領域の中だけの話）。⌘W はボードを選んでいる間は何も起こさない。制御 API の `close_tab` もボードを指せない（ボードには tabId が無く、`list_tabs` にも出ない）。

ボードを持つ workspace の最後のタブを閉じると（⌘W・中クリック・`close_tab`・シェル終了のいずれでも）ボードが選ばれ、空表示にはならない。ボードを選んでいる間に他のタブが閉じても（秘書の会話が終わったときを含む）、ボードは出たままで、閉じたタブの画面は残らない。

## 選んでいる間は「選んでいるタブが無い」

ボードには場所も面も無いので、選んでいる間は 0 タブと同じ規則に乗る。例外を作らないため。

- ⌘W・⌘R・⌘E・⌘⇧F・⌘F・⌘↑↓・⌘S・フォントの拡大縮小は何も起こさず、端末にも届かない。⌘⇧E はビープする。文字キーも何も起こさない。
- ⌘T・⌘⇧A・⌘⇧C・⌘⇧S・⌘⇧X・⌘⇧T・⌘,・⌘H・⌘⌘ はいつもどおり効く。新しいタブは workspace の root で起き、選ばれる。
- 上段の現在地と位置ドットは出ない。done のフォーカス消費・通知の抑制は効かない（見ているタブが無い）。
- 制御 API の `list_tabs` では、その workspace のどのタブも `active: false`。`focus_tab` でタブを指すと、そのタブが選ばれてボードから外れる。
- [秘書](../agent/secretary.md)・`start_task`・`select: false` の `spawn` が裏でタブを起こしても、ボードは出したままにしてそのタブを選ばない——裏で起こすタブを選んで見せるのは、何も出していなかった（空の）workspace だけで、ボードを持つ workspace は空にならない。

## 自動追加の部品

Home のボードは、タスクを生む仕組み（タスクの自動追加）を頼み、見て、手で動かす場所。1 件ずつのタスクをさばく ⌘⇧X とは階層で分ける。部品は見出し「タスクの自動追加 4 件」・その下の依頼の欄・左の一覧と右の選んだものの詳細で 1 つ。下にボードのフッターを出す。自動追加を作る・書き換えるのは AI の仕事なので、ボードでは定義を書き換えず、人は依頼の欄から頼む。

画面は自動追加のストアと走らせ役を毎回読み、値を写さない。持つのは選択（同一性。欄か一覧の行のどれか 1 つ）と欄の中身だけ。だから裏の回の確定・AI による変更や削除・⌘⇧X での操作はすぐ映り、選択は同じ自動追加に付いていく（消えたら同じ位置の行、末尾で頭打ち。一覧に居る間に行がすべて消えれば欄）。並びが変わっても選んだ自動追加は替わらない。

### 依頼の欄

見出しの下の欄（「❯ やりたいことを入力（例: Slack の自分宛ての DM をタスクの候補にして）」、右に「↵ 依頼」）に打って ↵ を押すと、その文がタスクの自動追加の依頼として[秘書](../agent/secretary.md)の頼みの列に入り、欄が空になる。欄に打った文はどれも自動追加の依頼として届く——欄は自動追加を頼む口で、だから自動追加の部品の中にある。

- 空か空白だけの欄の ↵ は何もせず、何も出さない。日本語入力の変換を確定する ↵ では送らず、↵ を押し続けても送るのは 1 回だけ。
- 受けたときは文字で知らせない。頼みが届けば秘書のタブが増えて見えるため。claude が無ければフッターの右に赤で「claude が見つからないので依頼できない」と出し、欄はそのまま。
- ボードに出る文言（欄・フッター・断り）には「秘書」の語を出さない。人にとっての口は「タスクの自動追加を頼む」欄で、誰が受けるかは中の話のため。
- 打ちかけの文字は保存しない（Orbe を終了すると消える。⌘⇧X の入力欄と同じ）。

### 直しを依頼

一覧で自動追加を選んで ⌘↵ を押すと、その場でその自動追加の直しを頼む（「タスクの自動追加 3「Backlog: 担当課題」を直す。」の 1 行）。焦点は一覧に残り、受けたときは文字で知らせない。直し方を細かく伝えたいときは、欄にふつうに書けば自動追加の依頼として届く。

- 頼む相手は押した時点のストアから引く。もう消えていれば頼まず、フッターの右に赤で「その自動追加はもうありません」を出す。claude が無ければ赤で「claude が見つからないので依頼できない」。

### 一覧

1 行に点・名前・いつ・前回の結果を出す。

- **並び**: 前回が失敗したもの（止めていない）→ それ以外（止めていない）→ 止めているもの。群の中は ID 順。走っているかは並びに効かない——走り出すたびに行が跳ねないため。
- **いつ**: 「30 分ごと · 次 17:00」「毎日 9:00・13:00 · 次 10/5 9:00」。止めていれば次を出さない。
- **右端**: 走っていれば「実行中…」（強調色）、止めていれば「止めている」、まだ回っていなければ「まだ回っていない」、前回が失敗なら「13:00 · 失敗」（赤）、成功なら「16:30 · 候補 2 件」か「16:00 · 新しい項目なし」。この順で上が勝つ。失敗の理由は詳細の回の記録で読む。
- **点と名前**: 前回が失敗（止めていない）なら赤、止めていれば沈んだ色、それ以外は強調色。止めている名前は減光する。色だけに意味を載せず、右端の文字でも言う。

並び・点・右端は「走っているか・止めているか・前回の結果」を 1 回だけ導いた値から読む。同じ判定が 4 か所に散ると、優先順位が 1 か所だけずれるため。

### 詳細

選んだ自動追加の名前と、取得・判定の指示・いつ・回の記録を出す。

- **取得**は 1 行の要約にせず、やり方（軽い agent なら CLI・モデル・使えるツール・依頼文、コマンドならコマンド・作業ディレクトリ）と取得の性質を全文で出す。承認なしで裏で走るものを、いつも確かめられるため。
- **判定の指示**は CLI・モデルと指示文の全文。
- **いつ**は止めていれば「（止めている）」を添える。
- **回の記録**は新しい順に最大 20 件、⌘⇧X の前回と同じ書き方で 1 行ずつ。「今すぐ」で回った回は時刻の後に「今すぐ」を添え、失敗は理由の全文を赤で折り返す。

長ければ詳細の欄がスクロールし、選択が替わると先頭へ戻る。取得・判定の何をどの順に、どこを原文として出すかは ⌘⇧X の中身と 1 か所で組み立て、字の大きさと箱は画面ごとに決める（ボードは原文も素の文字で描く）。

### キー

キーは焦点のある場所（欄か一覧）で意味が替わる。欄の「↵ 依頼」と一覧の「↵ 今すぐ実行」は別の場所のキーで、欄では space・↵ が文字の入力・送信になり、一覧の操作にならない。

欄は一覧の上の 1 段で、欄と一覧の行は 1 つの選択を分け合う——⌘⇧X で入力の行き先と一覧の行が 1 つの選択の同一性なのと同じ作法。選ばれて見えるのは常に 1 か所で、焦点の場所は選択から決まる。

- 欄を選んでいる間は、どの行も選ばれた見た目にならず、詳細を出さずに一覧が幅いっぱいを使う（⌘⇧X で入力の行き先を選んでいる間に右の欄を出さないのと同じ。詳しく見る自動追加が選ばれていない）。欄の枠は強調色になる。
- 一覧の行を選んでいる間は、欄は控えめな枠になる。
- ↑↓ は欄と一覧の行を 1 つの並びとして端で巡回する。欄の ↓ は一覧の先頭、先頭の行の ↑ は欄、欄の ↑ は一覧の末尾、末尾の行の ↓ は欄へ移る。欄から一覧へは、並びの次（先頭の行）か巡回した先（末尾の行）へ移る。

一覧に焦点がある間:

| キー | 動き |
|---|---|
| ↑↓ | 選択。先頭の ↑・末尾の ↓ は欄へ（押し続ければ流れる） |
| space | 止める ⇄ 再開 |
| ↵（修飾なし） | 今すぐ実行 |
| ⌘↵ | 直しを依頼（その場で頼む） |
| ⌘⌫ | 確認なしで削除。同じ位置の行が選ばれる |

欄に焦点がある間:

| キー | 動き |
|---|---|
| ↵ | 依頼 |
| ↓ | 一覧の先頭へ |
| ↑ | 一覧の末尾へ |
| esc | 一覧の先頭へ（↓ と同じ） |

自動追加が 0 件なら、欄の ↑↓ は何もしない。

- space・↵・⌘↵・⌘⌫ は押した瞬間だけを操作にし、押し続けたキーリピートでは何も起きない。取り消せない操作を繰り返さないため。削除に確認を挟まないのはタスクの ⌘⌫ に揃えたため。
- 日本語入力の変換中の ↵・↑↓・esc は変換へ渡る。
- 走っている間の ↵ は断り、フッターの右に赤で「実行中のため今すぐ実行できません」を出す。
- space・↵・⌘⌫ の 3 つの操作は、キー・キーの表示・名前・断りまで ⌘⇧X の[自動追加タブ](../palette/intake.md)の中身と 1 つの定義を共有する。画面ごとにキーと表示が食い違わないため。⌘↵ はこの定義に入れない（⌘⇧X の中身では何もしないキーで、共有の定義はボードの都合を持たない）。
- 一覧のほかのキー（⇥・⌘↑↓・文字キーなど）と欄の ⇥ は何も起こさず、焦点もボードの外へ出ない。

フッターの右の断り（赤）は 1 枠で、次の操作（↑↓・space・↵・⌘↵・⌘⌫・esc・行のクリック・欄に打つ）で消える。フッターの左は焦点のある場所で効くキーで、ボタンは置かない。

- 一覧: 「↑↓ 選択 · space 止める（止めていれば 再開） · ↵ 今すぐ実行 · ⌘↵ 直しを依頼 · ⌘⌫ 削除」。自動追加が 0 件なら出さない。
- 欄: 「↵ 依頼 · ↓ 一覧へ」。自動追加が 0 件なら「↓ 一覧へ」は出さない。

行のクリックで選ぶ。ポインタが乗っただけでは選択を動かさない——ボードは常に出ている画面で、ポインタが横切るたびに詳細が替わるのを避けるため。

### 時刻

「今日」「次 17:00」などの時刻の文言は分の境で描き直す。開きっぱなしの画面に、日をまたいだ「今日」や過ぎた「次」が残らないため（⌘⇧X は開いた時点で固定）。

### 0 件

自動追加が無ければ見出しは「0 件」、一覧の場所に「タスクの自動追加はまだありません」を出し、詳細と一覧のキーは出さない。依頼の欄はいつもどおり出て、選ばれるのは欄だけ。

## 焦点

ボードの面は、エディター面と同じく、焦点（first responder）が自分の中にあるときだけ chrome キーを受ける。焦点が欄にあっても同じ。端末タブを選んでいる間ボードは隠れて窓に残るが、焦点が無いので欄にも一覧にもキーが届かない。

焦点の宛先はボードの中身（自動追加の部品の欄と一覧の 2 か所）にあり、ボードの面そのものは焦点を受けない。面が焦点を受けられると、中身に焦点が無いままキーが黙って飲まれる状態が生まれうるため。

- 最初の焦点は一覧の先頭の行（選べばすぐ space・↵ が効く）。0 件なら欄。
- ボードを選ぶ・パレットを閉じる・workspace を切り替えて戻ると、選んでいる場所（欄か一覧）へ戻る。
- 欄に焦点が来ると、打ってあった文は全文が選ばれる（AppKit の入力欄の既定。⌘⇧X の入力欄と同じ）。打てば置き換わり、→ で末尾から続けられる。
- クリックは中身へ届く。欄を押せば欄、行を押せばその行、一覧の地を押せば一覧（欄から来たなら先頭の行）、それ以外の地を押せば選んでいる場所へ焦点が移り、続けてキーが効く。

## 空の状態

部品を 1 つも持たないボードは、中央に沈んだ一文（「まだ何も置かれていません」）だけを出す。字種と色はエディター面の空状態と同じ。Home のボードは自動追加の部品を持つので、今これは出ない。地は端末・エディター面と同じ veil で、背景不透明度の設定にライブで追従する。

## 保存

ボードを選んでいたかは workspace ごとに保存し、再起動後も戻る（→ [persistence](../platform/persistence.md)）。どの workspace がボードを持つかは保存しない（Home であることから決まる）。
