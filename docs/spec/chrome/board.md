# ボード

ボードは、workspace がタブの並びとは別に持つ 1 枚の面。端末の代わりに content を占めるが、タブではない——端末 surface を持たず、閉じられず、並びの中で動かない。今ボードを持つのは [Home](../platform/workspace.md#home) だけで、中身はまだ空の状態の一文だけ。

タブの並びの外に置くのは、タブの並びが「端末 surface 1 枚」を前提に、制御 API・Attention・保存・秘書の判定から広く読まれているため。ボードを混ぜると、それらすべてに例外が要る。どの workspace がボードを持つかは store の 1 つの判定が決め、workspace 自身は知らない。

## タブ行での位置と見え方

ボードを持つ workspace では、タブ行（[chrome](chrome.md)）の左端、横スクロール領域の外にボードのセルが固定される。セルは単独タブの器（無彩色の地・小さな角丸）に家のグリフと workspace 名を載せ、右に細い区切り線を置く。選択中はタブと同じく前景色を反転する。ラベルは workspace 名なので、Home を改名すれば追随する。

スクロール領域の外にあるので、タブが多くて横スクロールしてもセルは左端に残り、タブの幅の配分・並び替えのドラッグの幾何にも入らない。セルの幅は、タブに配る利用可能幅から先に引く。

## 選び方と巡回

セルのクリックでボードを選ぶ。⌘⇧] / ⌘⇧[（⌘⇧→ / ⌘⇧← も同じ）は「ボード → タブ 1 … タブ n → ボード」を 1 つの環として回る。ボードを選んでいる間もこのキーで巡回できる。タブが 0 枚なら、巡回してもボードのまま。

workspace の選択は「何も無い／ボード／どのタブか」の 1 つの値で、タブは位置ではなくタブそのものを指す。並び替え・連の再編・タブの追加で並びが変わっても、同じタブを指し続ける。

## 消えない・動かない

ボードは閉じる操作を受けない。セルには中クリック・右クリックのメニュー・ドラッグを付けていない。タブをボードの左へ落とすこともできない（並び替えはスクロール領域の中だけの話）。⌘W はボードを選んでいる間は何も起こさない。制御 API の `close_tab` もボードを指せない（ボードには tabId が無く、`list_tabs` にも出ない）。

ボードを持つ workspace の最後のタブを閉じると（⌘W・中クリック・`close_tab`・シェル終了のいずれでも）ボードが選ばれ、空表示にはならない。ボードを選んでいる間に他のタブが閉じても（秘書の会話が終わったときを含む）、ボードは出たままで、閉じたタブの画面は残らない。

## 選んでいる間は「選んでいるタブが無い」

ボードには場所も面も無いので、選んでいる間は 0 タブと同じ規則に乗る。例外を作らないため。

- ⌘W・⌘R・⌘E・⌘⇧F・⌘F・⌘↑↓・⌘S・フォントの拡大縮小は何も起こさず、端末にも届かない。⌘⇧E はビープする。文字キーも何も起こさない。
- ⌘T・⌘⇧A・⌘⇧C・⌘⇧S・⌘⇧X・⌘⇧T・⌘,・⌘H・⌘⌘ はいつもどおり効く。新しいタブは workspace の root で起き、選ばれる。
- 上段の現在地と位置ドットは出ない。done のフォーカス消費・通知の抑制は効かない（見ているタブが無い）。
- 制御 API の `list_tabs` では、その workspace のどのタブも `active: false`。`focus_tab` でタブを指すと、そのタブが選ばれてボードから外れる。
- [秘書](../agent/secretary.md)・`start_task`・`select: false` の `spawn` が裏でタブを起こしても、ボードは出したままにしてそのタブを選ばない——裏で起こすタブを選んで見せるのは、何も出していなかった（空の）workspace だけで、ボードを持つ workspace は空にならない。

## 焦点

ボードの面は、エディター面と同じく、焦点（first responder）が自分の中にあるときだけ chrome キーを受ける。端末タブを選んでいる間ボードは隠れて窓に残るが、焦点が無いのでキーを取らない。ボードを選ぶ・パレットを閉じる・workspace を切り替えると、焦点はボードへ戻る。面のどこをクリックしても焦点を取る。

## 空の状態

中央に沈んだ一文（「まだ何も置かれていません」）だけを出す。字種と色はエディター面の空状態と同じ。地は端末・エディター面と同じ veil で、背景不透明度の設定にライブで追従する。

## 保存

ボードを選んでいたかは workspace ごとに保存し、再起動後も戻る（→ [persistence](../platform/persistence.md)）。どの workspace がボードを持つかは保存しない（Home であることから決まる）。
