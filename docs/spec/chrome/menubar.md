# メニューバー投影

メニューバーに常駐アイテムを 1 個持つ。Attention の単一情報源（`AttentionStore`）をそのまま投影し、アプリ内の Attention パレットと同じ値を読む。目的は **Orbe を前面化せずに「今どのエージェントが待っているか」へ到達できること**。加えて、タスクの待ちの条件が解けた瞬間（→ [tasks](../platform/tasks.md)）も、同じピルで知らせる。文言は現在言語に追従する（[localization](../platform/localization.md)）。

メニューバーはアプリのテーマ強制ではなく**システム外観**で描かれるため、アイテムの見えはシステムの Light/Dark に追従し、切替に即応する。静的な状態（①③④）のグリフ・数字は前景モノクロ（他の常駐メニューバーアイコンと同じ template 相当の見え）。アイテムの幅は常に content の内容幅そのもの——メニューバーは子ビューの制約を幅に読まないため、幅は content の intrinsic から明示反映する。②の開閉が進んでいる間はこれを毎 tick 行う。

## 4 態

4 態は**一つのピル**が姿を変えたものであり、態の切り替わりで幅は飛ばない。

- **① 静か（要対応 0）**: 減光したブランドグリフのみ。`working` しかない間もここ（件数は `waiting`+`done` だけを数える）。地を持たないので水平余白も持たない。
- **② 滲み出しピル（状態変化・待ちが解けた瞬間）**: 中身が横へ滲み出るピル。詳細は次節。
- **③ 収縮後（要対応 1 件以上）**: グリフ＋件数のピル。件数は `waiting`+`done` のみ。
- **④ ドロップダウン表示中**: ③のピル地を accent tint にして「開いている」ことを示す。

## ② 滲み出しピル

出どころは 3 つある。エージェントのタブの状態変化と、タスクの待ちの条件が解けた瞬間と、[秘書](../agent/secretary.md#応えない秘書を知らせる)が応えないこと。どちらも 1 つの知らせとして一度だけ組まれ、このピルと通知音（→ [agent/sound](../agent/sound.md)）はその知らせを映す 2 つの面——立つ条件も読む設定も面ごとに判断しない。

**立つ条件（エージェント）**: エージェント報告（[agent/notify](../agent/notify.md)）が `waiting` / `done` への**実変化**のときだけ。同じ状態の連続報告では立たない。`working` は立てない。加えて、そのタブが**見ているタブ**（→ [chrome](chrome.md)）なら立てない——端末にその結果もプロンプトも出ている面で、注意だけを二重に奪わないため。タブの状態グリフ・横断件数ストリップ・③の件数・④のドロップダウン・Attention パレットには従来どおり出る。

**立つ条件（タスク）**: 待ちの条件が解けた瞬間（確認のコマンドが成功した・期限が来た）。Orbe を終了している間に期限を過ぎた条件も、起動直後に解けて立つ。複数あれば 1 件ずつ到来し、後の到来が前のピルを差し替える。Orbe が前面で、[⌘⇧X](../palette/tasks.md) のタスクのタブでそのタスクを選んでいるときは立てない——詳細欄に起きたことがその場で現れているため。一覧に行が見えているだけでは「見ている」に入れない。タスクの知らせは③の件数・④のドロップダウン・Attention パレットには入らない。

**立つ条件（秘書）**: 秘書を起こしてから最初の報告、頼みを貼ってから届いた確証が、30 秒のうちに来なかったとき。秘書のタブを見ているときは立てない。③の件数・④のドロップダウン・Attention パレットには入らない。

**中身**: ブランドグリフ・印・ワークスペース名・本文。印・ワークスペース名・本文は**一つの箱**として畳まれ、左から一続きに現れ／消える。

- エージェント: 印は状態グリフ、本文は hook 文言の先頭。文言を持たない報告ではタブタイトルを本文に据える。
- 秘書: 印は入力待ちの状態グリフ、ワークスペース名は Home の名前、本文は「秘書が応答しない — タブで確かめる」（到来の時点の言語）。
- タスク: 印は丸に ✓、ワークスペース名はタスクの workspace の名前（workspace が無ければ名前の欄を出さない）、本文は「#214 レビューが付いた」——主の結び付きの番号（無ければタイトル）と起きたこと（確認の出力の 1 行目。空なら「条件を満たした」、期限なら「期限が来た」）。本文は到来の時点の言語で組む。

**到来**: 1 つの知らせ（エージェントの報告・タスクの待ちが解けた瞬間・秘書が応えないこと）が 1 つの到来をなし、次の順で進む。

1. **展開 840ms** — ピルが開いて中身が現れる。既存の件数は同時に仕舞う。
2. **艶の走査**（到来から 1.2 秒後に 1.1 秒かけて）— 白い帯が左から右へ**通り抜ける**。1 つの到来につき 1 回だけ。
3. **滞留** — 長さは設定「メニューバー通知の表示時間」（既定 40 秒・5〜180 秒・→ [settings](../palette/settings.md)）。**発信元（タブ・タスク）の workspace の実効値**をピルが立つ瞬間に読む（workspace の無いタスクは全体の値）——どの workspace で起きたことかが長さに出る（通知音と同じ読み方）。滞留は到来の属性で、その到来が終わるまで動かない。設定を変えても今出ているピルの残り時間は変わらず、次の到来から効く。ホバーしている間は収縮せず、ホバーが外れてからの余韻ぶんだけ先送りする。
4. **収縮 600ms** — 中身が畳まれ、同時に件数が現れる。艶が走っている最中に閉じ始めたら艶は止む。

滞留中に別の知らせが届けば中身が差し替わり、艶が**もう一度**走って滞留を数え直す（展開はやり直さない。ただし立つ条件で抑制される変化は差し替えを起こさない）。

**件数**: ②が立っている間、件数は**姿にも幅にも出ない**——中身は文言が語る。閉じた姿が示すのは常に実件数で、②の間に届いた変化はそこにまとめて現れる。②が立っている間の姿（地・水平余白・ブランドグリフの減光）は**到来した瞬間の件数**に従うので、到来のあとで一覧が追いついても姿は跳ねない。

**取り下げ**: エージェントのピルは、**ピルが指す行が一覧から外れた時点で取り下げる**。ピルは一覧の投影なので、そのタブが `working` へ戻った・`idle` へ落ちた・`clear` された・閉じられたときは滞留を待たずに消える。判定は行の再計算に相乗りする（→ 行の集合と更新）。行が残っている間の中身（ワークスペース名・本文）は更新しない——中身が変わるのは新しい変化の報告が立て直したときだけ。タスクと秘書のピルは一覧の投影ではなく出来事の知らせなので、取り下げは無い——滞留が尽きるかクリックで閉じる。解けたタスクは ⌘⇧X の行に残る。

**閉じ方**: 閉じ方は収縮ひとつで、経路によって変わるのは尺だけ。滞留を満了したときは 600ms、取り下げと②の間のアイテムクリック（Orbe を前面化して**行き先へ直行**する。エージェントはそのタブへ focus、タスクは ⌘⇧X を開いてそのタスクを選ぶ、秘書は秘書のタブへ focus。ドロップダウンは開かない）は 180ms で、どちらも中身が畳まれて同時に件数が現れる。閉じ切った時点でピルを落とす。タスクを選ぶとき、範囲・入力・畳んだ完了の欄で隠れていれば見えるように切り替え、エージェントは起こさない。言語選択・オンボーディング・更新内容の画面が出ている間は前面化だけで、⌘⇧X に差し替えず、エージェントのタブへも移らない——ピルのクリックはキー操作と違い、その画面が焦点を握っていても届くため（タブへ移ると焦点だけが裏の端末へ移り、画面に向けた esc・↵ が agent に届く）。取り下げ済み・閉じかけのピルへのクリックは②のクリックではなく通常のクリック（ドロップダウンの開閉）として扱う。

**Reduce Motion**: 展開・収縮・艶を止める。②は開いた姿で即座に現れ、滞留のぶんだけ出て、即座に閉じてその瞬間に件数が現れる（時間も情報も落とさない）。

**地とインク**: このピルだけは自前の不透明な暗地を持ち、その地に合わせてインクを解決する——メニューバーの実背景は壁紙由来の半透明で、地を透かす塗りでは文字も状態グリフも読めないため。艶はこの地の上を通るので、地に対する白として解決する。

**幅の契約**: ピル全体に上限がある（メニューバーの他アイテムを圧迫しないため）。その内側予算を左から順に配る。

- ワークスペース名スロットは**自分の上限までの範囲で内容へハグ**する（上限いっぱいを占有しない。超えた分は省略）。
- 本文スロットは上限を宣言せず**残り予算を吸う**（超えた分は省略）。
- 件数スロットは**値によらず自分の上限ぶんを予約する**。

つまり**ワークスペース名が短いほど本文が長く出る**。どちらのスロットも提案幅では膨らまない＝短い本文ならピルはそのぶん縮む（内容ハグ）。

予算配分は**畳み具合を見ない**。到来の途中で予算が動くと本文の省略位置が毎フレーム変わって文字が跳ねるため、配分は到来のあいだ不変な量だけから組む。件数の値は到来の途中で変わるので、件数スロットの予約も値から取らない。

## ④ ドロップダウン

**開く**: アイテムのクリック（②の間を除く）、または**背面からの ⌘⌘**（Accessibility / Input Monitoring のどちらかの権限があるときだけ。権限の付与・剥奪は前面化のたびに再評価する）。アイテムが隠れている（メニューバーから外された・溢れた）ときは錨が画面に無いので no-op。前面時の ⌘⌘ はドロップダウンではなくアプリ内の Attention パレットを開く（→ [attention](../palette/attention.md)。素タップの判定もそちら）。ただしドロップダウンが開いている間はパネル自身がキーなので ⌘⌘ はそちらへ届き、**開けたものと同じジェスチャで閉じる**——背面のメインウィンドウでパレットが無言で開くのを防ぐため。

アプリを前面化せずに開き、パネル自身がキーになるので Esc / ⌘O を受ける。アイテム直下・右揃えに出し、画面端では可視領域へクランプする。**閉じる**: 外クリック・キー喪失・Esc・行クリック・アイテムの再クリック・⌘⌘。

**中身**（上から）:

- `waiting` / `done` の行リスト。行の形は Attention パレットと共用（状態グリフ・ワークスペース名・タブタイトル・右端に経過時間、文言があれば下段に折り返し）。0 件なら「対応するものはありません」の 1 行。
- 区切り線の下に `working` の減光集約 1 行（件数とワークスペース名の列挙）。クリック不可。0 件なら出ない——**進行中はここに畳み、要対応だけを一覧に立てる**のがこの面の分け方。
- フッター: 「クリックでそのタブへ」＋「orbe を開く ⌘O」。
- 権限未付与のときだけ、その下に控えめなヒント 1 行。

**操作**: 行クリック＝Orbe を前面化してそのタブへ移動（workspace の activate ＋タブ選択＋端末 focus）。⌘O とフッター右＝前面化のみ。権限ヒントのクリック＝前面化して設定パレットを開く（権限状態の行はそこにある → [settings](../palette/settings.md)）。言語選択・オンボーディング・更新内容の画面が出ている間は前面化だけで、その画面を差し替えず、タブへも移らない。

## 行の集合と更新

投影する行は **activated（materialize 済み）タブのみ**で、エージェント状態が `waiting` / `done` / `working` のタブを状態変化時刻の降順に並べる。背景workspaceへ明示的に作成されmaterializeされたタブも含み、同じworkspaceに残る未materializeタブは含まない。`idle` と未報告は出さない。件数と一覧は `waiting`+`done` のみで、`working` は集約 1 行が受ける。

snapshot は chrome と同じ coalesce 契機で更新する（[chrome](chrome.md)）——メニューバー専用の走査タイミングは作らない。ドロップダウンの経過時間だけは表示中に自走する。
