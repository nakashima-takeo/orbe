# リンクを開く

端末上のリンクを ⌘クリックすると、libghostty が `OPEN_URL` アクションで host に URL 文字列を渡し、host（Orbe）が macOS の作法で開く。この action は常に処理済みを返し、libghostty のフォールバックオープナーは使わない。C 側の文字列ポインタはコールバック中だけ有効なため、bytes を即コピーしてから main で扱う。

リンクには由来が 2 種ある。`OPEN_URL` の `kind` がそれを区別し、Orbe はこの区別で開き方を分ける。

- **正規表現で検出したリンク**（`kind` が `unknown`／`text`／`html`）: libghostty が画面の文字列から http URL やファイルパスとして検出したもの。**見えている文字列そのものが対象**なので、隠された対象は存在しない。
- **OSC 8 ハイパーリンク**（`kind` が `osc8`。`printf '\e]8;;URL\e\\text\e]8;;\e\\'`）: 端末出力が表示文字列と別に URL を指定する。**見えている文字列と無関係な対象を仕込める**ので、端末出力を信頼しない経路に通す。

## 正規表現で検出したリンク

見えている文字列を対象として、判定を挟まず開く。

- 解決は純関数: scheme 付きはそのまま URL、scheme 無しは `~` を展開してファイル URL とみなす。
- `kind==text` は既定エディタ（拡張子の既定アプリ → プレーンテキストの既定アプリの順）で開き、それ以外は URL の既定アプリで開く。

## OSC 8 ハイパーリンク

入力は URL 文字列だけ。判定は文字列・ローカル host 名の集合・ファイルシステムの状態から決まる純関数で、結果は 3 値。

| 判定 | 意味 |
|---|---|
| **allow** | そのまま開く。実行を伴わず挙動が定まっている対象。 |
| **confirm** | 対象と開き先アプリ名を見せて人が決める。任意のアプリを起動できる対象。 |
| **block** | 開かず、理由を示す。 |

### 規則（上から順に最初に当たったもの）

1. 不可視・制御・行分割文字（C0/C1 制御、方向制御、ゼロ幅、行・段落区切り、Word Joiner、BOM）を含む → **block（不可視文字）**。表示と実体が食い違う手口をパースの前に断つ。
2. scheme 無し・解釈不能 → **block（不正形式）**。相対参照を後段が勝手に解決しない。
3. `http`／`https`: host があれば **allow**、無ければ **block（host 無しの web）**。
4. `mailto`: 宛先があれば **allow**、無ければ **block（不正形式）**。
5. `file`:
   - query／fragment 付き → **block（不正形式）**。ファイルシステム上の対象を指さない。
   - host が空・`localhost`・**このマシンのホスト名**（プロセスが名乗る hostName と `Host.current()` の全名。大文字小文字を区別しない）のいずれでもない → **block（別ホストのファイル）**。coreutils `ls --hyperlink`・ripgrep `--hyperlink-format=default`・fd・cargo は `file://<gethostname()>/path` を出すので、このマシンの名前はローカルと認める——ここが上流 Ghostty（空か `localhost` のみ）との差で、日常のファイルリンクを壊さないため。
   - `..` と symlink を解決した実体が存在する通常ファイルかディレクトリでない（デバイス・ソケット等） → **block（存在しない／特殊ファイル）**。
   - 実体が実行されうるもの → **block（実行されうるファイル）**。実行ビット付きの通常ファイル、application／executable／script の UTI に準拠するもの、`.app`・`.command`・`.pkg`・`.scpt`・`.webloc`・`.terminal` 等の実行されうる拡張子（実行ビットが無くても Launch Services は拡張子でハンドラを選ぶ）。
   - それ以外 → **allow**。開くのは解決後の URL。`kind==text` の既定エディタ選択は適用しない（OSC 8 は text/html の情報を持たない）。
6. それ以外の scheme（`vscode://`・`cursor://`・`man:` 等） → **confirm**。

### 確認・ブロックの見せ方

NSAlert（終了確認・エディタ未検出と同じ作法）。文言は surface の窓の現在言語で引き、窓が無ければ OS 追従。surface の窓があればシートで出し、無ければアプリモーダル。表示は action コールバック（描画ロック中）ではなく main の次の turn に回す。

- **confirm**: 「端末出力のリンクを開きますか？」と開き先アプリ名（Launch Services の登録アプリ。無ければ「既定のアプリ」）、ボタンは「キャンセル（既定）」「開く」。
- **block**: 「Orbe はこのリンクを開きませんでした」と理由、ボタンは「OK」「リンクをコピー」。コピーするのは表示文字列で、開く近道は作らない（ホスト名が変わった直後に自分のファイルが「別ホスト」と判定されたときの逃げ道もこれ）。

どちらも対象文字列を等幅・選択可の欄に出す。`file` は解決後のパス、それ以外は元の文字列で、不可視文字は `\u{XXXX}` に可視化する。Orbe はリンクのホバー表示を持たないので、このダイアログが真の対象を人に見せる唯一の場所。

### 境界

- 判定は ⌘クリック時に 1 回、main で同期に行う（存在確認・UTI 取得の I/O を伴う。ネットワークボリュームで待たされ得るが、判定を省く方が危険）。
- OSC 8 の検出自体は libghostty の `link-osc8`（既定 true）が持つ。無効化したいユーザーは `~/.config/ghostty` で切る。
- 正規表現で検出したリンクの挙動は OSC 8 の規則の影響を受けない。
