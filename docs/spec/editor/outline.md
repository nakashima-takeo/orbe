# アウトライン

焦点の文書のクラス・メソッド・プロパティなどを、エクスプローラーの下段に入れ子の木で出す。行を押せばその名前へ飛び、キャレットを動かせば今いるシンボルの行が光る。振る舞いは VS Code のアウトラインビューの既定に揃え、揃えない所は末尾に挙げる。見た目は [design-system](../../design/design-system.md) §5 の Outline。

## 区画

エクスプローラーは縦 2 段——上がツリー（→ [shell](shell.md)）、下がアウトライン。アウトラインの見出しを押すと開閉し、既定は閉。閉じている間は見出しだけがパネルの下端に残り、ツリーが残りを全部取る。開いている間は、2 段の境（見出しの上の縁）をドラッグして高さを変えられ、両方の区画に行 3 本ぶんの最小の高さが残る。高さはパネルの高さに対する比で持つので、窓の高さが変わっても比は変わらない。開閉と比は**アプリ全体で 1 つ**で、再起動でも戻る（→ [persistence](../platform/persistence.md) の app-state）。見出しにホバーしている間だけ、右端に「すべて折りたたむ」（子を持つ最上位の行がどれも開いていなければ「すべて展開」）が 1 つ出る。アウトラインはエクスプローラーのパネルにだけ出る（検索パネルには無い）。

## 何を出すか

焦点の文書のシンボルを、位置順の入れ子の木で出す。行はシェブロン（子があるときだけ）・種類のチップ・名前。言語ごとの粒度は VS Code がその言語の既定の言語サーバで出すものに合わせる。

| 言語 | 出るもの |
|---|---|
| Swift | 型（class・struct・enum・protocol・actor）・extension・関数とメソッド・init / deinit・プロパティと最上位の変数（`var a = 1, b = 2` は 1 つずつ）・enum の case・typealias・`// MARK:` の区切り（名前は印を外した字）。関数はセレクタの形（`emit(_:coalesce:)`） |
| TypeScript / TSX / JavaScript | class・interface・enum・type・namespace・関数・メソッド・プロパティ・変数（関数の中の変数も）。テストの呼び出し（`describe` / `test.each(…)(…)` など）に渡した関数も 1 つの項目 |
| Python / Go / Rust | class・def / 型・func・メソッド（Go は `(*Server).Start`。関数の中の型やフィールドは出さない）/ struct・enum・trait・impl・fn・mod・const など。Python は同じ入れ子の中の同じ名前を 1 つにまとめる（型の付いた最後の宣言、無ければ最初の宣言） |
| Markdown | 見出し（名前は `## 見出し` のように段の数の印を含む。setext 見出しも同じ、閉じの `#` は含めない）。見出しの段で入れ子になる |
| JSON / YAML / TOML | キー（JSON はエスケープをほどいた値で、改行は `↵`、空白だけのキーは引用符で囲む。配列の要素は番号）。TOML はテーブルとキー |
| CSS | セレクタ（カンマで並んだものは 1 つずつ）と `@media` などの規則。`@keyframes` は接頭辞の付いたものも `@keyframes 名前` |
| HTML | 要素（名前は `tag#id.class`） |
| Bash | 関数 |
| Dockerfile | ファイルの頭のパーサーディレクティブ（`# syntax=…`。名前はディレクティブの名）と、命令を平らに並べる（名前は命令の語） |

シンボルの範囲は、その前に続く属性・デコレータ・doc コメントを含む（Rust は rust-analyzer と同じく、属性と外側の doc コメントは空行を挟んでも、普通のコメントは空行を挟まない限り含める。TS はクラスの中身の前のデコレータ）。飛び先はその言語のサーバが指す名前の字（Go のメソッドはメソッド名、Rust の impl は対象の型）。

取り出しは文書の根の構文木だけを見る——HTML の script / style の中身、Markdown のコードブロック、JS のテンプレートの中のシンボルは出さない。件数に上限は置かない（大きな JSON では数万〜10 万行になる）。文法の無いファイル・空の文書・取り出し中は、VS Code と同じ 3 つの文言を出す（取り出し中の文言は、すぐに届けば出さない）。

シンボルを取り出す規則は Orbe 自身の資源として言語ごとに持つ（→ [code](code.md) の色付けと同じく tree-sitter の問い合わせ。出どころとライセンスは [licensing](../platform/licensing.md)）。

## 取り出しの時機と版

- **取り出すのは、アウトラインが見えている間の焦点の文書だけ**。閉じている間・エクスプローラー以外のパネル・面が隠れている間は何も計算しない。
- 打鍵が続く間は取り直さず、打鍵が止んで（色の見えていない範囲を作り始めるのと同じ静けさ）から、今の本文で 1 回取り直す。それまでは前の結果を出し続ける。開いてから編集していなければ待たない。
- 取り出しは、打鍵にも色付けにも割り込まない専用の裏の仕事が行う。新しい本文が届けば、走っている取り出しを途中で打ち切る。1MB の文書でアウトラインを開いていても、打鍵 1 回の main の仕事は開いていないときと変わらない。取り直した結果を受け取るときも、前の結果は裏で手放すので、main の仕事はシンボルの数に依らない。
- 前の結果でも、飛び先とカーソル追従は**今の本文の位置で正しい**——結果は取り出した版の位置のまま持ち、問いと答えを版の間で写す。シンボルの本体を直しても範囲は消えずに伸び縮みし、名前を丸ごと書き換えれば飛び先はシンボルの頭になる。
- 切り替えて戻っただけの、編集していない文書は取り直さない。
- 開閉の状態は、シンボルが同じ名前の道筋（祖先の名前と種類）にある限り、取り直しをまたいで残る。

## 操作

- **単クリック**: 選んで、少し待って（ダブルクリックを待つ）名前の頭へキャレットを置く。焦点はアウトラインに残る。
- **ダブルクリック**: シンボルの範囲全体を選び、焦点を本文へ移す。子のある行のシェブロンのダブルクリックは 1 回だけ開閉する。
- **Enter**: 名前の頭へキャレットを置き、焦点を本文へ移す。
- 本文のスクロールは、飛び先が画面の外なら上寄せ（上に 5 行か高さの 2 割の広い方の間を空ける。範囲全体を選ぶときは終わりが下へ押し出されない範囲で。範囲が画面より高ければ先頭を上端に）、画面の中なら縦は動かさない。横に隠れていれば寄せる（面の「見えていなければ上寄りに」の方針→ [code](code.md#区間を見せる)）。
- **↑↓** は選ぶだけ（飛ばない）。**→** は畳んでいれば開き、開いていれば最初の子へ。**←** は開いていれば畳み、そうでなければ親へ。**Space** は開閉。**Home / End** は先頭・末尾の行を選ぶ。
- 行を押しても開閉しない。開閉はシェブロンで行う。
- VoiceOver にはリスト（行の総数・見えている行・選択の行）として見せる。

## カーソル追従

キャレットが止んで少し経つと、キャレットを含む最も深いシンボルが選ばれる。祖先が畳まれていれば開き、列の中で見えていなければ中央へ寄せる。焦点は奪わない。どのシンボルにも入らなければ選択を外す。取り直した結果が届いたときも同じことを 1 回行う（絞り込みの結果だけが変わったときは行わない）。

## 絞り込み

焦点がアウトラインにある間に文字を打つと、見出しの下に入力欄が出て、その字から絞り込む（日本語の入力も最初の字から効く。入力欄が出ている間に行から打った字は、入力欄の字の後ろに足す）。一致したシンボルとその祖先だけが残り、一致した字が強調される。並びは位置順のまま（点数では並べ替えない）。照合は VS Code の tree の絞り込みと同じ（あいまい一致）で、裏で行う。

- 字が変わるたびに、選んでいたシンボルが一致ならそのまま、そうでなければその後ろの最初の一致（末尾を過ぎれば頭から）を選ぶ。祖先として残っただけの行は選ばない。空になれば選択は動かさない。どの場合も、選んでいる行が見えていなければ中央へ寄せる。
- 絞り込んでいる間は、全部を開いた状態から始まるその間だけの畳みを使う（畳んだ親の下の一致も見える）。その間の開閉は解けば捨て、元の畳みに戻る。
- 入力欄の ↑↓ と Enter は行の操作になり、Esc で絞り込みを解いて行へ戻る。文書を切り替えると解ける。

## 状態と永続

- アプリ全体（app-state）: 開閉と区画の比（境を端まで引いた 0・1 も戻る）。
- 実行中だけ: 畳んだシンボル（文書ごと）・絞り込みの文字列。

## VS Code との差

- **カーソル追従は常にオン**で、「…」メニュー（追従・絞り込みの切替・並べ替え）を持たない。並びは位置順だけ。
- **名前の後ろの薄い字（detail）・問題のバッジを持たない**。
- **件数の上限を置かない**（VS Code の JSON は 5000 件で打ち切る）。
- **打鍵が止んでから取り直すまでの待ちは一律**（VS Code は実測に応じて伸ばす）。
- 言語サーバではなく構文木から取り出すので、名前の組み方に届かない所がある: TS / JS の呼び出しに渡した関数の名前（VS Code の `describe("x") callback`）・Swift の値を持つ case のラベル・TS の getter / setter の印は出さない。
- 入れ子は範囲の包含で決めるので、言語サーバが書かれた場所と違う親の下に置くものは揃わない: Python の `self.x = …`（Pylance はメソッドの中の代入でもクラスの子に出す）は出さず、TS の引数のプロパティ（tsserver はクラスの子）はコンストラクタの子に出る。
- **HTML の名前は、空の id・class と class の端の空白を印にしない**（VS Code は `class=""` を `section.` と出す）。
