# 面の機構

タブの中身は、エディター面と端末面を並べ、その境に引き手・継ぎ目を重ねた 1 枚の器で、ひとつのタブの中で端末とエディターを行き来する。エディター面はコードを開いて編集する場所（→ [code](code.md)）で、端末と同じ worktree に根を置く。切替はキー 1 つ、分割は引き手を引くだけ——別窓や別タブを増やさずに、今いる作業の隣にエディターを出す。

## 配置と記憶

タブ 1 枚が **面の配置**——エディター幅の割合（0…1）と焦点の面（端末かエディター）——を持つ。既定は端末だけ（割合 0・端末焦点）。タブを切り替えても自分の配置に戻り、再起動しても戻る（→ [persistence](../platform/persistence.md)）。

配置は**正規形**に限る: 割合 0 なら焦点は端末、1 ならエディター。したがって焦点の面は常に見えている面で、キーとフォーカスはその面へ届く（→ [layout](../chrome/layout.md) のフォーカス）。分割中（0 と 1 の間）だけ焦点はどちらでもよく、焦点がどの経路で面の中へ入っても（クリック・キー・面の中の入力欄）その面へ移る。

## 幅で決まる見え方

面の大きさは器の大きさから解く。全面（端末だけ・エディターだけ）は器いっぱいを使い、引き手は幅を取らずに面の上へ重なる——端末だけのときは端末が器の左端から始まる。分割中は両面が角丸のカードになり、器の内側に余白を取り、面と面の間を空けて並ぶ。余白と間にはタブ行と同じ沈んだ地が見え、分割していることが一目で分かる。分割で両面に分けるのは、器からその余白と間を除いた幅で、割合をその幅で解いて両面に幅が残るときだけ分割になる（残らなければ割合の近い側の全面）。器が余白と間より狭ければ分割できない。間は場所を取るので、分割に入る・出るときに面の大きさが余白と間のぶん変わる。面に最小幅は無い——中身の大きさは面の大きさそのもので、端末は 80 桁を割ってよい（狭くするかは人が継ぎ目で決める）。中身は面の上端から面いっぱいに置く。分割中は焦点の面のカードの上辺に、その面のキー色の細い帯（焦点の印）が重なる——場所を取らないので、焦点を移しても中身は動かない。クリックやドラッグは帯の下の中身へ届く。

## ⌘E

端末焦点でもエディター焦点でも同じに効く。分割していなければ端末 ⇄ エディター全面を往復し、分割中は焦点だけを往復する。0 タブでは何も起きない。ヘルプ表示中・タブ改名中は他の chrome キーと同じく不活性。

## 引き手と継ぎ目

面を開く・閉じる・分ける取っ手。面の見え方に応じて形を変える 1 つの取っ手で、全面では引き手、分割中は継ぎ目になる。

- **引き手**: 片面が隠れているとき、隠れた側の縁の縦中央に、幅を取らずに面の上へ重なる小さなタブ形。その面のキー色とグリフ（エディターはファイル形・端末は窓と ❯_）で、どの面が隠れているかを示す。端末だけなら左縁にエディターの引き手、エディター全面なら右縁に端末の引き手。普段は半透明で中身の邪魔をせず、ポインタが乗ると不透明になって浮く。
- **継ぎ目**: 分割中の面と面の間そのもの。縦中央に縦に並んだ 3 つの点がある。間のどこを掴んでも引ける。ポインタが乗ると間の地と点が明るくなり、引いている間もその明るさを保つ。

押せるのは引き手と、間の 3 つの点の周りだけ。間の他の部分は引くだけで、押して離しても配置も焦点も変わらない——掴みに行った間を押し損ねて、意図せず全面になるのを防ぐ。

- **押す**（動かさずに離す）: 隣が隠れていれば全開、自分が隠れていれば戻る、分割中（間の点）は焦点側で全面。
- **引く**: 間はポインタに連続で追従し、面の幅がそのまま変わる（吸着しない）。間は掴んだ点とポインタの位置関係を保って付いてくる——引き手から引き出しても、間はポインタの下に来る。離したときだけ確定する——どちらかの面を端ぎりぎりまで寄せていれば（使えない細さなら）その面は閉じて隣が全面になり、それ以外はその幅のまま。境は端ぎりぎりに限る狭さで、それより広い面は勝手に戻らない。両面がその狭さになる幅（分割で分ける幅がその 2 倍未満）では、離すとどちらかが必ず閉じ、分割は残らない。引いても離しても焦点の面は変わらない——焦点の面が閉じたときだけ、残る面へ焦点が移る（結果は常に正規形）。引いている間はタブの配置を書き換えず、離したときに 1 回だけ確定する。
- 引き手・間の点を掴んだ瞬間（間の他の部分は動き出した瞬間）に、そのタブの焦点の面へフォーカスを戻す。

ポインタの形は、引き手は指、継ぎ目は左右矢印。面に重なるのは引き手だけで、重なった範囲ではクリックとポインタの形は引き手が持ち、スクロールは下の面へ届く。引き手は押す・引くの道具で、下の面を読むのを妨げない。覆うのは小さな範囲——端末の左余白、またはエディターのスクロールバーの縦中央の一部——で、そこではスクロールバーのつまみや印が引き手の下に隠れる。

遷移（⌘E・引き手や間の点を押す・離したときに閉じる）は短いスライドで、面の clip と中身の位置だけが動く。動きの始めか終わりのどちらかが分割なら、その動きの間はカードで描く——分割から出るスライドはカードのまま滑り、着地の瞬間に器いっぱいへ戻る。⌘E の全面 ⇄ 全面はカードにならない。引き手は遷移中も縁に留まる。どのコマでも見えている面は中身で覆われる——隠れていく面・縮む面の中身は最後に見えていた寸法のまま錨側に付いて滑って面に切られ、現れる面・広がる面の中身は始めから行き先の寸法で入ってくる。中身の寸法（端末の pty のサイズ・エディターの配置）が変わるのは遷移の始めか終わりの 1 回だけ。離しても幅が変わらなければ即時に確定する。Reduce Motion では即時。引いている間の中身の resize は表示のフレーム単位に間引く。

## 端末面

端末は器に包まれても壊れない——scrollback は保たれ、pty のサイズは見えている端末面の寸法と一致し、隠れている間は寸法（幅と高さ）を据え置いて resize しない（→ [terminal/core](../terminal/core.md)）。

## ⌘⇧F

エディターを見せてプロジェクト検索の入力欄へ焦点を入れる（→ [search](search.md)）。端末焦点でも効き、エディターが隠れていれば全面、見えていれば焦点だけを移す。0 タブでは何も起きない。

## 位置ドットと現在地

タブ行の右端に位置ドット 2 点（エディター・端末）が、それぞれの面が見えているか・焦点かを示す。上段の現在地は焦点の面に追従する——端末焦点は実効 cwd、エディター焦点はエディターの根と焦点の文書（→ [chrome](../chrome/chrome.md)）。

## エディターの根

タブの cwd が属する git worktree ルート（タブ行の連と同じキー）。git 管理外は cwd。規則と、根ごとのサービス（監視・git 状態・baseline・一覧と新規作成）は [files](files.md) が持つ。

## 面の中身と空状態

面の中身は骨（→ [shell](shell.md)）——レール・サイドバー（エクスプローラーか[プロジェクト検索](search.md)のパネル。幅はドラッグで可変・レールで開閉）・ファイルタブ行・パンくず——で、焦点の文書（→ [code](code.md)）があればそのコードビューが列の本体に出る。無ければ本体に空状態——中央に沈んだ ◐ と一文、ショートカットの案内（⌘⇧F・⌘E）だけを置く。どちらも地は chrome と同じ veil で、背景透過の設定に追従する。文言は現在言語（→ [localization](../platform/localization.md)）。空状態の本体はどこをクリックしても面自身がフォーカスを取り、文書があればクリックはテキスト面へ届く。骨はクリックを自分で受ける。
