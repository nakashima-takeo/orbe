# 面の機構

タブの中身は、エディター面と端末面を並べ、その境に引き手・継ぎ目を重ねた器で、ひとつのタブの中で端末とエディターを行き来する。器は連（同じ worktree のタブの並び → [chrome](../chrome/chrome.md)）ごとに 1 つで、エディター面は連で共有し、端末面にはアクティブなタブの端末が出る。エディター面はコードを開いて編集する場所（→ [code](code.md)）で、端末と同じ worktree に根を置く。切替はキー 1 つ、分割は引き手を引くだけ——別窓や別タブを増やさずに、今いる作業の隣にエディターを出す。

## 配置と記憶

連 1 つが **面の配置**——エディター幅の割合（0…1）と焦点の面（端末かエディター）——と、エディターそのもの（タブの列——文書のタブと diff のタブ——・焦点のタブ・仮のタブ・undo・選択・スクロール・未保存の内容・プロジェクト検索 → [code](code.md)・[search](search.md)）を持つ。既定は端末だけ（割合 0・端末焦点）で、新しくできた連は端末だけで始まる。同じ worktree で作業するタブはどれも同じエディターを見る——同じファイルの未保存は 1 か所に集まり、同じ場所のタブを移っても配置と文書はそのまま残る。

連の中でタブを切り替えると、器もエディターも配置も焦点の面も動かず、端末だけが入れ替わる——閉じる・開くの動きは起きない。連の端末はどれも面の確定寸法に従うので（→ 端末面）、切り替えた瞬間に見える端末は既に正しい寸法で描かれていて、描き直しは起きない。別の連のタブへ移ると、器ごとその連のものに即時に替わる（滑らない）。再起動しても連ごとの配置とエディターが戻る（→ [persistence](../platform/persistence.md)。diff のタブは戻らない → [diff](diff.md)）。

配置は**正規形**に限る: 割合 0 なら焦点は端末、1 ならエディター。したがって焦点の面は常に見えている面で、キーとフォーカスはその面へ届く（→ [layout](../chrome/layout.md) のフォーカス）。分割中（0 と 1 の間）だけ焦点はどちらでもよく、焦点がどの経路で面の中へ入っても（クリック・キー・面の中の入力欄）その面へ移る。

前面のアクティブなタブが端末に焦点を置いたまま cd で別の連へ移ったら（→ [code](code.md) の連を移るとき）、行き先の連の焦点を端末にする。行き先がエディター全面なら端末だけの配置にする（その連の他のタブから見ても変わる）——打っていた端末が見えないまま、キーが見えない面へ届かないため。背景のタブの cd では行き先の配置に触らない。

## 幅で決まる見え方

面の大きさは、境の位置（割合 × 取りうる最大）から解く。全面（端末だけ・エディターだけ）は面が器いっぱいを取り、引き手は幅を取らずにその上へ重なる——端末だけのときは端末が器の左端から始まる。分割中は境に幅 12 の継ぎ目が全高で立ち、両面はその両側に並ぶ。縁の近くでは、両面の間の幅が縁からの距離に応じて 0〜12 になり、その間は継ぎ目の地で埋まる（取っ手の上下から窓の奥が透けない）。静止した境は点に丸めるので、面と中身はピクセルに揃う。面に最小幅は無い——中身の大きさは面の大きさそのもので、端末は 80 桁を割ってよい（狭くするかは人が継ぎ目で決める）。中身は面の上端から面いっぱいに置く。分割中は焦点の面の中身の上辺に、その面のキー色の細い帯（焦点の印）が重なる——場所を取らないので、焦点を移しても中身は動かない。クリックやドラッグは帯の下の中身へ届く。

## ⌘E

端末焦点でもエディター焦点でも同じに効く。分割していなければ端末 ⇄ エディター全面を往復し、分割中は焦点だけを往復する。0 タブ・ボード選択中は何も起きない。ヘルプ表示中・タブ改名中は他の chrome キーと同じく不活性。

## 引き手と継ぎ目

面を開く・閉じる・分ける取っ手。引き手と継ぎ目は 1 つの物で、境の位置から連続に形を変える。

- **引き手**: 縁にいるときの形。隠れた側の縁の縦中央に、幅を取らずに面の上へ重なる小さなタブ形で、その面のキー色とグリフ（エディターはファイル形・端末は窓と ❯_）で、どの面が隠れているかを示す。端末だけなら左縁にエディターの引き手、エディター全面なら右縁に端末の引き手。普段は半透明で中身の邪魔をせず、ポインタが乗ると不透明になって浮く。
- **継ぎ目**: 縁から離れたときの形。全高の幅 12 の地で、中央に縦棒が立つ。
- **その間**: 縁から離れるほど、高さが伸び、塗りが継ぎ目の地へ移り、枠と角が消え、グリフが縦棒に替わる。縁へ戻せば逆にたどる。形は位置を少し遅れて追う（ばね）——引き手を伸ばして引き出し、継ぎ目を縮めて縁へしまう手触りにするため。

取っ手は全体が押せる・掴める。

- **押す**（動かさずに離す）: 引き手なら反対の全面へ、継ぎ目なら焦点の側の全面へ。
- **引く**: 取っ手はポインタに 1:1 で付いていき、面の幅がそのまま変わる（吸着しない）。引いている間は連の配置を書き換えない。
- **離す**: 離す直前の勢いで少し先を見て、端の近くに届くならその面を閉じて隣を全面にする（勢いのまま滑る）。それ以外は離した位置で分割として確定し、行き過ぎない。止めてから離せば勢いは無い。端の近くで止めると、引き手と継ぎ目の中間の形のまま分割として残ることがある。引いても離しても焦点の面は変わらない——焦点の面が閉じたときだけ、残る面へ焦点が移る（結果は常に正規形）。確定は離したときの 1 回だけ。
- 位置が動いている途中でも掴める。掴むとその場で止まって手に渡り、動かさずに離せばその位置で離したことになる。
- 掴んだ瞬間に、その連の焦点の面へフォーカスを戻す。引いている途中でも、外から来た配置（⌘E・焦点の移動・制御 API）が勝ち、掴みは打ち切られる。

ポインタの形は、引き手は指、継ぎ目と引いている間は左右矢印。面に重なった範囲ではクリックとポインタの形は取っ手が持ち、スクロールは下の面へ届く。取っ手は押す・引くの道具で、下の面を読むのを妨げない。引き手が覆うのは縦中央の小さな範囲——端末の左余白と 1 桁目の左端（引き手の幅が継ぎ目の幅と揃うため、余白より少しはみ出す）、またはエディターのスクロールバーの一部——で、そこでのクリックとドラッグは引き手が受け、スクロールバーのつまみや印は引き手の下に隠れる。

⌘E・押す・閉じる着地は、位置のばねで行き先まで滑る——時間は決まっておらず、収束で止まる。引き手のクリックや ⌘E で全面を往復すると、引き手が継ぎ目に伸びて窓を横切り、反対の縁で引き手に縮む。どのコマでも見えている面は中身で覆われる——隠れていく面・縮む面の中身は最後に見えていた寸法のまま錨側に付いて滑って面に切られ、現れる面・広がる面の中身は始めから行き先の寸法で入ってくる。中身の寸法（端末の pty のサイズ・エディターの配置）が変わるのは動きの始めか、位置と形の両方が止まった終わりの 1 回だけで、押しただけでは変わらない。引いている間の中身の resize は表示のフレーム単位に間引く。Reduce Motion では、位置は即時に移り、形は位置にそのまま連動する（引いている間の伸び縮みは残る）。

## 端末面

端末は器に包まれても壊れない——scrollback は保たれ、pty のサイズは見えている端末面の寸法と一致し、端末面が隠れている間は寸法（幅と高さ）を据え置いて resize しない（→ [terminal/core](../terminal/core.md)）。

端末面には連の起きているタブの端末がすべて入り、見せるのはアクティブなタブの 1 枚。見せていない兄弟の端末も、端末面の確定寸法（窓の resize・分割の幅の確定）に従う——連の中で切り替えるたびに pty の resize と再折り返しが起きないため。引いている間と動きの途中で寸法を配るのは見せている端末だけで、確定したときに兄弟へ配る。端末面が隠れている間に連へ入った端末は、戻したときに得る寸法で起きる。

## ⌘⇧F

エディターを見せてプロジェクト検索の入力欄へ焦点を入れる（→ [search](search.md)）。端末焦点でも効き、エディターが隠れていれば全面、見えていれば焦点だけを移す。0 タブ・ボード選択中は何も起きない。

## 位置ドットと現在地

タブ行の右端に位置ドット 2 点（エディター・端末）が、それぞれの面が見えているか・焦点かを示す。上段の現在地は焦点の面に追従する——端末焦点は実効 cwd、エディター焦点はエディターの根と焦点のタブのファイル（文書のタブも diff のタブも同じ。→ [chrome](../chrome/chrome.md)）。

## エディターの根

連のキー——連のタブの cwd が属する git worktree ルート。git 管理外は cwd。規則と、根ごとのサービス（監視・git 状態・版の本文・一覧と新規作成）は [files](files.md) が持つ。

## 面の中身と空状態

面の中身は骨（→ [shell](shell.md)）——レール・サイドバー（エクスプローラーか[プロジェクト検索](search.md)のパネル。幅はドラッグで可変・レールで開閉）・タブ行・パンくず——と、列の本体。本体は焦点のタブで 3 種に分かれる——**文書**（焦点の文書のコードビュー → [code](code.md)）・**diff**（インラインなら新しい側の面 1 枚、並列なら左右 2 面と境の線、表示できなければ理由の一文 → [diff](diff.md)）・**空**（タブが無い）。本体の矩形・右列・焦点の行き先・当たり・検索バー・⌘S・列の頭の高さはこの種類で分かれる。空状態は中央に沈んだ ◐ と一文、ショートカットの案内（⌘⇧F・⌘E）だけを置く。どれも地は chrome と同じ veil で、背景透過の設定に追従する。文言は現在言語（→ [localization](../platform/localization.md)）。文字だけの本体（空状態・diff の一文）はどこをクリックしても面自身がフォーカスを取り、面があればクリックはテキスト面へ届く。骨はクリックを自分で受ける。
