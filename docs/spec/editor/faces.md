# 面の機構

タブの中身は「エディター面 ＋ 背 ＋ 端末面」の 1 枚の器で、ひとつのタブの中で端末とエディターを行き来する。エディター面はコードを開いて編集する場所（中身は今は空状態だけ）で、端末と同じ worktree に根を置く。切替はキー 1 つ、分割は背を引くだけ——別窓や別タブを増やさずに、今いる作業の隣にエディターを出す。

## 配置と記憶

タブ 1 枚が **面の配置**——エディター幅の割合（0…1）と焦点の面（端末かエディター）——を持つ。既定は端末だけ（割合 0・端末焦点）。タブを切り替えても自分の配置に戻り、再起動しても戻る（→ [persistence](../platform/persistence.md)）。

配置は**正規形**に限る: 割合 0 なら焦点は端末、1 ならエディター。したがって焦点の面は常に見えている面で、キーとフォーカスはその面へ届く（→ [layout](../chrome/layout.md) のフォーカス）。分割中（0 と 1 の間）だけ焦点はどちらでもよく、面をクリックするとその面へ移る。

## 幅で決まる見え方

面の幅は器の幅から解く。背は固定幅で常に立ち、残りを割合で分ける。内容幅が分割の成立幅に満たないときは、記憶した割合を保ったまま焦点側の 1 枚へ吸着する（窓を広げれば分割に戻る）。面が縮んでも中身は潰れず、最小幅を保って錨側（エディターは右・端末は隣にエディターがあれば右、無ければ左）へ滑り出る。分割中は焦点の面の上辺にその面のキー色の細い帯が立つ。

## ⌘E

端末焦点でもエディター焦点でも同じに効く。分割していなければ端末 ⇄ エディター全面を往復し、分割中は焦点だけを往復する。0 タブでは何も起きない。ヘルプ表示中・タブ改名中は他の chrome キーと同じく不活性。

## 背

面の継ぎ目に立つ細い帯。両面が見えているときはグリップ（無彩の棒）、片面が隠れているときはその面の印（面のキー色のグラデと面のグリフ）になり、カーソルでも押せる／引けるが分かる。

- **動かさずに離す**: 隣が隠れていれば全開、自分が隠れていれば戻る、分割中は焦点側で全面。
- **引く**: 連続の分割。離す前に吸着する——閉じる閾値未満で 0、最小幅未満は最小幅へ押し上げ、端末の最小幅を残す上限で止まり、上限と全開の中点から先は全開。分割が成立しない幅では半分で 0 か全開。右端まで引き切ればエディターが焦点になり、左端まで戻せば端末が焦点になる（結果は常に正規形）。
- 掴んだ瞬間に、そのタブの焦点の面へフォーカスを戻す。

遷移（⌘E・背のクリック）は短いスライドで、面の clip と中身の位置だけが動く。Reduce Motion では即時。

## 端末面

端末は器に包まれても壊れない——scrollback は保たれ、pty のサイズは見えている端末面の幅と一致し、隠れている間は resize しない（→ [terminal/core](../terminal/core.md)）。

## 位置ドットと現在地

タブ行の右端に位置ドット 2 点（エディター・端末）が、それぞれの面が見えているか・焦点かを示す。上段の現在地は焦点の面に追従する——端末焦点は実効 cwd、エディター焦点はエディターの根（→ [chrome](../chrome/chrome.md)）。

## エディターの根

タブの cwd が属する git worktree ルート（タブ行の連と同じキー）。git 管理外は cwd。

## 空状態

エディター面はまだファイルを開けないので、中央に沈んだ ◐ と一文、ショートカットの案内（⌘⇧F・⌘E）だけを置く。地は chrome と同じ veil で、背景透過の設定に追従する。文言は現在言語（→ [localization](../platform/localization.md)）。
