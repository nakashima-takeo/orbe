# 面の機構

タブの中身は、端末面の上にエディター面を重ねた器で、規則は 1 つ——**タブは端末、⌘E はエディター**。タブを選べばそのタブの端末が出て、⌘E を押すとエディターが端末の領域いっぱいに重なり、もう一度押すと閉じて端末に戻る。器は連（同じ worktree のタブの並び → [chrome](../chrome/chrome.md)）ごとに 1 つで、エディター面は連で共有し、端末面にはアクティブなタブの端末が出る。エディター面はコードを開いて編集する場所（→ [code](code.md)）で、端末と同じ worktree に根を置く。別窓や別タブを増やさずに、今いる作業の上にエディターを出す。

## 開閉の規則

開いているかは窓が 1 つだけ持つ——「エディターで見せているタブ」で、無ければ閉じている。あるなら、それは前面の workspace で選んでいるタブ。見せるタブが替われば閉じるので、画面に出ていない連が開いたまま残ることはない。

連 1 つはエディターそのもの（タブの列——文書のタブと diff のタブ——・焦点のタブ・仮のタブ・undo・選択・スクロール・未保存の内容・プロジェクト検索 → [code](code.md)・[search](search.md)）を持つ。閉じてもエディターの中身は連に残り、⌘E で開き直せば元の文書・選択・スクロール位置のまま出る。同じ worktree で作業するタブはどれも同じエディターを見る——同じファイルの未保存は 1 か所に集まる。

開閉は保存しない。起動し直すと、どの連も端末で始まる。開いていた文書の列は連の状態として残り（→ [persistence](../platform/persistence.md)。diff のタブは戻らない → [diff](diff.md)）、⌘E を押せば元のとおり出る。

見せているタブの端末が cd で別の worktree へ移っても（→ [code](code.md) の連を移るとき）、開閉は変わらない。端末を見せていれば行き先でも端末、エディターで見せていれば行き先の連のエディターが出る。

操作ごとの結果（エディターを開いているとき）:

| 操作 | 結果 |
|---|---|
| タブ行でタブをクリックする（今のタブのクリックを含む） | そのタブの端末 |
| タブ切り替えのキー（⌘⇧[ ]・⌘⇧←→） | 移った先のタブの端末（ボードへ巡回したらボード） |
| 新しいタブを開く（⌘T・＋・エージェントの起動など、開いたタブがそのまま選ばれるもの） | 新しいタブの端末 |
| Attention パレット・メニューバー・タスク画面からタブへ移る、制御 API の `focus_tab` | そのタブの端末 |
| 閉じたエージェントを戻す（⇧⌘T） | 戻したタブの端末 |
| 見ているタブを閉じて、隣のタブが選ばれる | 隣のタブの端末 |
| workspace を切り替える（制御 API の `activate_workspace` を含む） | その workspace で選んでいるタブの端末 |
| ボードを選ぶ | ボード |
| ⌘⇧F、制御 API の `open_file` / `open_diff` | エディター（別のタブが対象なら、そのタブへ移ってエディター） |
| 選んでいないタブが閉じる・増える（背景のエージェントの終了、選ばれずに裏で開くタブ） | エディターのまま |
| 見ているタブの端末が cd で別の worktree へ移る | エディターのまま（行き先の worktree のエディター） |
| パレットやヘルプを開いて閉じる、窓が背面へ回って戻る | エディターのまま |

別の workspace のタブへ移る操作は、workspace・選ぶタブ・エディターで見せるかを先に決めてから 1 回だけ描く——移り先ではないタブを途中で描かない。

連の中でタブを切り替えると、器もエディターも動かず、端末だけが入れ替わる。別の連のタブへ移ると、器ごとその連のものに即時に替わる。

## 重なり方と開閉の動き

端末面・その中の端末・エディター面は常に器いっぱいで、エディター面は端末面の上に重なる。引いて幅を変える操作は無い。閉じている間はエディター面を隠し（根のサービスを離す → [files](files.md)）、開いている間は下の端末面を隠す——エディター面の地は半透明の veil なので、下の端末を描き続けると地が二重に重なり文字も透ける（→ [layout](../chrome/layout.md)）。

開閉の動きはエディター面の濃さの短いフェード 1 つ（長さは動きのトークンの `base` → [design-system](../../design/design-system.md)）。フェードするのは、同じタブを見せたまま開閉が変わるとき（⌘E・⌘⇧F・今のタブのクリック・今見せているタブへの `open_file` / `open_diff`）だけで、見せるタブが替わるときは即時。開閉の状態・焦点・クリックの届き先は押した瞬間に切り替わり、動くのは見た目だけ。

| 開閉 | 動きの途中か | エディター面 | 端末面 | クリックの届き先 |
|---|---|---|---|---|
| 閉 | いいえ | 隠す | 見せる | 端末 |
| 開 | はい | 見せる（濃さ → 1） | 見せる | エディター |
| 開 | いいえ | 見せる（濃さ 1） | 隠す | エディター |
| 閉 | はい | 見せる（濃さ → 0） | 見せる | 端末 |

途中で反転したら、今見えている濃さから逆へ続ける。「途中」が解けるのは最後に始めた動きが終わったときだけ——開く → すぐ閉じる → すぐ開く、のどの順でも両面の可視は表のとおり。閉じる途中のエディター面はクリックを取らない（取ると、隠れていく view に焦点が残る）。器が画面に出ていないとき（窓に無い・隠れている）と「視差効果を減らす」のときは、即時に切り替わる。

## ⌘E

端末でもエディターでも同じに効く。選んでいるタブのエディターを開き、開いていれば閉じる。開けば焦点はエディター面の焦点の行き先へ、閉じればそのタブの端末へ移る。0 タブ・ボード選択中は何も起きない。ヘルプ表示中・タブ改名中は他の chrome キーと同じく不活性。

## 端末面

端末は器に包まれても壊れない——scrollback は保たれ、pty のサイズは常に器の寸法と一致する。開閉で pty のサイズは変わらず、エディターに覆われている間も窓の resize には追従する（→ [terminal/core](../terminal/core.md)）。開いている間は描画だけが止まる。

端末面には連の起きているタブの端末がすべて入り、見せるのはアクティブなタブの 1 枚。見せていない兄弟の端末も器の寸法に従う——連の中で切り替えるたびに pty の resize と再折り返しが起きないため。

## ⌘⇧F

エディターを開いてプロジェクト検索の入力欄へ焦点を入れる（→ [search](search.md)）。端末からでも効き、閉じていれば開く。開いたまま押し直してもエディターを描き直さず、焦点を動かすのは検索パネルが入力欄へ焦点を入れる 1 回だけなので、打っている途中の入力欄から焦点が離れない。0 タブ・ボード選択中は何も起きない。

## 現在地

上段の現在地は見せているものに追従する——端末で見せていれば実効 cwd、エディターで見せていればエディターの根と焦点のタブのファイル（文書のタブも diff のタブも同じ。PR の diff のタブは根の代わりに PR の番号。→ [chrome](../chrome/chrome.md)）。どちらの面かは画面と現在地で分かる。

## エディターの根

連のキー——連のタブの cwd が属する git worktree ルート。git 管理外は cwd。規則と、根ごとのサービス（監視・git 状態・版の本文・一覧と新規作成）は [files](files.md) が持つ。

## 面の中身と空状態

面の中身は骨（→ [shell](shell.md)）——レール・サイドバー（エクスプローラー・[プロジェクト検索](search.md)・[ソース管理](source-control.md)・[PR](pull-request-panel.md)のパネル。幅はドラッグで可変・レールで開閉）・エディターのタブ行・パンくず——と、列の本体。本体は焦点のタブで 3 種に分かれる——**文書**（焦点の文書のコードビュー → [code](code.md)）・**diff**（インラインなら新しい側の面 1 枚、並列なら左右 2 面と境の線、表示できなければ理由の一文 → [diff](diff.md)）・**空**（タブが無い）。本体の矩形・右列・焦点の行き先・当たり・検索バー・列の頭の高さはこの種類で分かれる。空状態は中央に沈んだ ◐ と一文、ショートカットの案内（⌘⇧F・⌘E）だけを置く。どれも地は chrome と同じ veil で、背景透過の設定に追従する。文言は現在言語（→ [localization](../platform/localization.md)）。文字だけの本体（空状態・diff の一文）はどこをクリックしても面自身がフォーカスを取り、面があればクリックはテキスト面へ届く。骨はクリックを自分で受ける。
