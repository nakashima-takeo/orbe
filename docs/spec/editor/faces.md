# 面の機構

タブの中身は、端末面の上にエディター面を重ねた器で、規則は 1 つ——**タブは端末、⌘E はエディター**。タブを選べばそのタブの端末が出て、⌘E を押すとエディターが端末の領域いっぱいに重なり、もう一度押すと閉じて端末に戻る。開いている間、⌥ だけを押している間は、エディターを開いたまま下の端末が見える。器は連（同じ worktree のタブの並び → [chrome](../chrome/chrome.md)）ごとに 1 つで、エディター面は連で共有し、端末面にはアクティブなタブの端末が出る。エディター面はコードを開いて編集する場所（→ [code](code.md)）で、端末と同じ worktree に根を置く。別窓や別タブを増やさずに、今いる作業の上にエディターを出す。

## 開閉の規則

開いているかは窓が 1 つだけ持つ——「エディターで見せているタブ」で、無ければ閉じている。あるなら、それは前面の workspace で選んでいるタブ。見せるタブが替われば閉じるので、画面に出ていない連が開いたまま残ることはない。

連 1 つはエディターそのもの（選んだ画面——Changes / PR / Files——・Files の開いている文書の列と今の文書と仮の文書・Changes の diff と PR の diff・undo・選択・スクロール・未保存の内容・プロジェクト検索 → [shell](shell.md)・[code](code.md)・[search](search.md)）を持つ。閉じてもエディターの中身は連に残り、⌘E で開き直せば元の画面・文書・選択・スクロール位置のまま出る。同じ worktree で作業するタブはどれも同じエディターを見る——同じファイルの未保存は 1 か所に集まる。

開閉は保存しない。起動し直すと、どの連も端末で始まる。開いていた文書の列と選んでいた画面は連の状態として残り（→ [persistence](../platform/persistence.md)。diff は戻らない → [diff](diff.md)）、⌘E を押せば元のとおり出る。

見せているタブの端末が cd で別の worktree へ移っても（→ [code](code.md) の連を移るとき）、開閉は変わらない。端末を見せていれば行き先でも端末、エディターで見せていれば行き先の連のエディターが出る。

操作ごとの結果（エディターを開いているとき）:

| 操作 | 結果 |
|---|---|
| タブ行でタブをクリックする（今のタブのクリックを含む） | そのタブの端末 |
| タブ切り替えのキー（⌘⇧[ ]・⌘⇧←→） | 移った先のタブの端末（ボードへ巡回したらボード） |
| 新しいタブを開く（⌘T・＋・エージェントの起動など、開いたタブがそのまま選ばれるもの） | 新しいタブの端末 |
| Attention パレット・メニューバー・タスク画面からタブへ移る、制御 API の `focus_tab` | そのタブの端末 |
| 閉じたエージェントを戻す（⇧⌘T） | 戻したタブの端末 |
| 見ているタブを閉じて、隣のタブが選ばれる | 隣のタブの端末 |
| workspace を切り替える（制御 API の `activate_workspace` を含む） | その workspace で選んでいるタブの端末 |
| ボードを選ぶ | ボード |
| ⌘⇧F、制御 API の `open_file` / `open_diff` | エディター（別のタブが対象なら、そのタブへ移ってエディター） |
| 選んでいないタブが閉じる・増える（背景のエージェントの終了、選ばれずに裏で開くタブ） | エディターのまま |
| 見ているタブの端末が cd で別の worktree へ移る | エディターのまま（行き先の worktree のエディター） |
| パレットやヘルプを開いて閉じる、窓が背面へ回って戻る | エディターのまま |

別の workspace のタブへ移る操作（自動化の知らせから Home のボードへ移る操作も同じ）は、workspace・選ぶもの・エディターで見せるかを先に決めてから 1 回だけ描く——移り先ではないタブを途中で描かない。

連の中でタブを切り替えると、エディターは閉じ（中身は連に残る）、器は替わらずに端末だけが入れ替わる。別の連のタブへ移ると、器ごとその連のものに即時に替わる。

## 重なり方と切り替わりの動き

端末・エディター面は常に器いっぱいで、エディター面は端末面の上に重なる。器の見せ方は 3 つ——端末・エディター・透かし（後述の ⌥）。閉じている間はエディター面を隠し（根のサービスを離す → [files](files.md)）、開いている間は下の端末面を隠す——エディター面の地は半透明の veil なので、下の端末が見えていると地が二重に重なり文字も透ける（→ [layout](../chrome/layout.md)）。隠すのは画面に出さないためだけで、見せている端末の描画は続ける（→ [terminal/core](../terminal/core.md)）。描画を止めておくと、端末を見せ直した最初のフレームに古い出力か何も描かれていない状態が出るため。透かしている間は、エディター面の上のバー（→ [shell](shell.md)）を残し、バーより下だけを濃さ 0 にする——バーの右下に開いているポップアップ（Changes のコミットのポップアップ → [source-control](source-control.md)）と、その下に並ぶ札（Changes の実行中の札・失敗の札）もバーより下に在るので見えなくなる（閉じない）。面の中の確認（破棄の確認 → [shell](shell.md#面の中の確認とフォーカス)）は上のバーも覆うが、透かしている間は幕ごと見えなくなる（閉じない。焦点も動かない）。端末面はバーの下端から下だけを見せる——端末の大きさと位置は変えないので、桁数・行数は変わらない。背景を透過させた窓で、バー越しに端末が透けないため。面の地（veil）はバーの分とバーより下の分に分けて塗り、重ねない——透かしの間にバーより下の地だけを見えなくするため。

切り替わりの動きは濃さの短いフェードで、濃さが変わる切り替えだけが動く。端末とエディターの間はエディター面全体の濃さを、エディターと透かしの間はバーより下の濃さを動かし、長さは動きのトークンで前者が `base`、後者が `quick`（→ [design-system](../../design/design-system.md)）。端末と透かしの間は即時。開閉のフェードは、同じタブを見せたまま開閉が変わるとき（⌘E・⌘⇧F・今のタブのクリック・今見せているタブへの `open_file` / `open_diff`）だけで、見せるタブが替わるときは即時。見せ方・焦点・クリックの届き先は押した瞬間に切り替わり、動くのは見た目だけ。

| 見せ方 | 動いている濃さ | エディター面 | バーより下 | 端末面 | クリックの届き先 |
|---|---|---|---|---|---|
| 端末 | 無し | 隠す | — | 見せる（全体） | 端末 |
| エディター | 無し | 見せる（濃さ 1） | 濃さ 1 | 隠す（描画は続く） | エディター |
| 透かし | 無し | 見せる（濃さ 1） | 濃さ 0 | 見せる（バーの下端から下） | 無し（器が受ける） |
| 端末 | エディター面 | 見せる（濃さ → 0） | 濃さ 1 | 見せる（全体） | 端末 |
| エディター | エディター面 | 見せる（濃さ → 1） | 濃さ 1 | 見せる（全体） | エディター |
| エディター | バーより下 | 見せる（濃さ 1） | 濃さ → 1 | 見せる（バーの下端から下） | エディター |
| 透かし | バーより下 | 見せる（濃さ 1） | 濃さ → 0 | 見せる（バーの下端から下） | 無し（器が受ける） |

途中で反転したら、今見えている濃さから逆へ続ける。「途中」が解けるのは最後に始めた動きが終わったときだけ——開く → すぐ閉じる → すぐ開く、のどの順でも両面の可視は表のとおり。閉じる途中のエディター面はクリックを取らない（取ると、隠れていく view に焦点が残る）。器が画面に出ていないとき（窓に無い・隠れている）と「視差効果を減らす」のときは、即時に切り替わる。

## ⌘E

端末でもエディターでも同じに効く。選んでいるタブのエディターを開き、開いていれば閉じる。開けば焦点はエディター面の焦点の行き先へ、閉じればそのタブの端末へ移る。0 タブ・ボード選択中は何も起きない。ヘルプ表示中・タブ改名中は他の chrome キーと同じく不活性。

## ⌥ で端末を透かす

エディターを開いている間、⌥ だけを押し続けると、上のバーを残してその下のエディターが消え、下の端末が見える（透かし）。離すとエディターに戻る。上のバーの右の「⌥ 端末を表示」は、透かしている間だけ押している間の姿になる（→ [shell](shell.md) の上のバー）。エディターは開いたままで、焦点・開いていた文書・上段の現在地（エディターのまま）・エディターの中身は動かない。エディター面は隠さず見えなくするだけなので、IME の変換・複数カーソル・入力欄の焦点も途切れない。透かしは保存しない。

- **始まる**: ⌥ だけを押して 0.2 秒たったとき。ただし、その間にほかのキー・マウスのボタンの押下が無く、その時点でポインタが ⌥ を押したときの位置から 4pt を越えて動いていないときに限る。左右どちらの ⌥ でも同じ。⌥ を使うエディターの操作（⌥クリック・⌥ドラッグ・⌥＋字・⌥←→・⌥⌘↑↓）とは、この間合いとポインタの位置で見分ける——⌥ を押してから 0.2 秒たつ前のクリック・ドラッグ・キーと、待つ間にポインタを 4pt 越えて動かした（0.2 秒たった時点で、押したときの位置から離れている）後の操作は、今までどおり働く（→ [code](code.md)）。ポインタを動かさずに 0.2 秒より長く押してからのクリック・ドラッグは、透かしが始まって端末が出るので、どこにも届かない（⌥ を離して押し直す）。キーは透かしを終えてからエディターへ届く（後述の「透かしている間の入力」）。
- **見送る**: 待つ間にほかの入力があった押下、⌥ 以外の修飾が加わった押下、マウスのボタンを押している最中の ⌥（ドラッグ中の ⌥ でコピー）では透かさない。見送った押下は、修飾キーを全部離すまで次を始めない。ポインタの位置を見るのは 0.2 秒たった時点だけで、透かし始めた後に動かしても透かしは続く。
- **始めない**: パレットやヘルプなど、オーバーレイが出ている間。
- **終わる**: ⌥ を離したとき・⌥ 以外の修飾が加わったとき・キーを打ったとき・窓が前面でなくなったとき・エディターが閉じたか別のタブのエディターに替わったとき（タブ行でタブを選ぶ・制御 API の `focus_tab` / `open_file` / `open_diff` など）。エディターが閉じた・替わったときは、⌥ を押したままでも、修飾キーを全部離すまで次を始めない。透かしている間は修飾キーの今の状態を短い間隔で確かめ、⌥ だけでなくなっていれば終わる——メニューを開いている間・窓をドラッグしている間・別のアプリへ移った後は、⌥ を離したイベントが Orbe に届かないので、イベントだけに頼ると端末が出たままになるため。
- **透かしている間の入力**: 見るだけ。上のバーと端末の領域でのクリック・右クリック・スクロールは、器が受けて端末にもエディターにも届けない——バーは見えるが押せない。見えないエディターのボタンを押す事故と、端末へ焦点が移る食い違い（⌥ を離すとエディターが戻るのに、キーは隠れた端末へ入る）を避けるため。タブ行など器の外は今までどおり効く。キーを打つと、その時点で透かしが終わってから、キーは今までどおりエディターへ届く。ポインタの動き（ホバー）は、見えている端末へ届く。
- **見ているタブ**: 透かしている間は端末の結果が目の前に出ているので、そのタブを見ているタブに数える（→ [chrome](../chrome/chrome.md)）。

出入りは濃さのフェードで、長さは `quick`（「視差効果を減らす」では即時）。

## 端末面

端末は器に包まれても壊れない——scrollback は保たれ、pty のサイズは常に器の寸法と一致する。開閉で pty のサイズは変わらず、エディターに覆われている間も窓の resize には追従する（→ [terminal/core](../terminal/core.md)）。開いている間は端末面を隠すが、見せている端末の描画は続ける。

端末面には連の起きているタブの端末がすべて入り、見せるのはアクティブなタブの 1 枚。見せていない兄弟の端末も器の寸法に従う——連の中で切り替えるたびに pty の resize と再折り返しが起きないため。描くのは器が見せている 1 枚だけで（エディターに覆われていても描く）、見せていない兄弟の端末と、画面に出ていない器の端末は描かない（→ [terminal/core](../terminal/core.md)）。

## ⌘⇧F

エディターを開き、Files の画面を選んで左の列を検索パネルにし（左の列を閉じていれば開く）、プロジェクト検索の入力欄へ焦点を入れる（→ [search](search.md)）。端末からでも効き、閉じていれば開く。開いたまま押し直してもエディターを描き直さず、焦点を動かすのは検索パネルが入力欄へ焦点を入れる 1 回だけなので、打っている途中の入力欄から焦点が離れない。0 タブ・ボード選択中は何も起きない。

## 現在地

上段の現在地は見せているものに追従する——端末で見せていれば実効 cwd、エディターで見せていれば連が画面から導く値（→ [chrome](../chrome/chrome.md)）。Files は根と今の文書（文書が無ければ根だけ）、Changes は根だけ、PR は worktree の今の PR の番号と根（PR が分からなければ根だけ）。PR の番号は worktree の今の PR の答えが替われば描き直す。どちらの面かは画面と現在地で分かる。

## エディターの根

連のキー——連のタブの cwd が属する git worktree ルート。git 管理外は cwd。規則と、根ごとのサービス（監視・git 状態・版の本文・一覧と新規作成）は [files](files.md) が持つ。

## 面の中身と空状態

面の中身は骨（面の中身の構造 → [shell](shell.md)）——上のバー（→ [shell](shell.md#上のバー)）と左の列（エクスプローラー・[プロジェクト検索](search.md)・[ソース管理](source-control.md)・[PR](pull-request-panel.md)のパネル。幅はドラッグで可変・バーのボタンと ⌘B で開閉）——と本体。本体は連の画面で決まり、3 種に分かれる——**文書**（Files の今の文書のコードビュー → [code](code.md)）・**diff**（Changes・PR の画面の diff。上端にそのファイルの見出しの帯、その下に、インラインなら新しい側の面 1 枚、並列なら左右 2 面と境の線、表示できなければ理由の一文。インラインか並列かは本体の幅で決まる → [diff](diff.md)）・**空**（Files で文書が無い、Changes・PR で diff が無い）。本体の矩形・右列・焦点の行き先・当たり・検索バーはこの種類で分かれる。どれも地は chrome と同じ veil で、背景透過の設定に追従する。

出すものが無い・表示できないときの決まりは 1 つ——左の列はパネルの題の行の下に短い一言、本体は中央に見出しと案内の一文と、あればボタンかショートカットの行。出すものがまだ決まらない間（git 管理下かの判定の前・読み込み中・diff が自動で開く前）は本体に何も出さない。

| 画面 | 状態 | 左の列 | 本体 |
|---|---|---|---|
| Files | 文書を開いていない | エクスプローラーか検索パネル | 見出し「ファイルを開いて編集を開始」と、ショートカットの 2 行「プロジェクト全体を検索 ⌘⇧F」「ターミナルへ戻る ⌘E」 |
| Changes | git 管理外 | 「表示できません」 | 見出し「変更を表示できません」と、理由の一文「このフォルダは git で管理されていません」 |
| Changes | 変更なし | 親「ソース管理」の見出しの下に「変更なし」（グラフの枠は出る） | 見出し「変更なし」と、一文「作業ツリーは HEAD と同じです。」 |
| Changes・PR | diff を表示できない（バイナリ・競合など） | 一覧 | 理由の一文（→ [diff](diff.md)） |
| PR | open の PR が無い | 「プルリクエストなし」 | 見出し「プルリクエストなし」と、一文「このブランチのプルリクエストは、まだありません。」と、ボタン「プルリクエストを作成」。ブランチが GitHub に無いと確かめられた間は、一文が「先にブランチを公開してください」で、ボタンは押せない姿（→ [pull-request-panel](pull-request-panel.md#作成の入口)） |
| PR | 表示できない（git 管理外・ブランチに居ない・既定のブランチ・GitHub のリポジトリでない・確かめられない・gh が無い・gh が認証されていない） | 「表示できません」 | 見出し「プルリクエストを表示できません」と、理由の一文 |
| PR | 問い合わせの失敗・中身の最初の読みの失敗 | 「表示できません」 | 見出し「プルリクエストを表示できません」と、失敗の文と、ボタン「再読込」 |
| PR | 中身が読めて、変更ファイルが無い | PR のパネルの列 | 見出し「変更ファイルなし」と、一文「このプルリクエストで変更されたファイルはありません。」 |

文言は現在言語（→ [localization](../platform/localization.md)）。文字だけの本体（空・使えないときの表示・diff の理由の一文）は、ボタンのほかはどこを押しても面自身がフォーカスを取り、ボタンは押してもフォーカスを取らない。本体にテキスト面（→ [code](code.md)）があれば、クリックはそこへ届く。骨はクリックを自分で受ける。
