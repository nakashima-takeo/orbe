# 秘書

秘書は、人の頼みを受けるたびに [Home](../platform/workspace.md#home) で claude を 1 つ起こすしくみ。人は[タスク画面](../palette/tasks.md)（⌘⇧X）で打った文を ⌘↵（agent に任せる）で、[Home のボード](../chrome/board.md#自動追加の部品)の依頼の欄の文を ↵ で、一覧で選んだ自動追加の直しを ⌘↵ で頼む。Orbe はその頼みを最初の入力にして claude を起こし、Home へ切り替えてそのタブを選ぶ。claude は役目どおりにタスクを足す、または自動追加の定義を書く・直す。

1 依頼 1 会話にしているのは、届ける時機（手が空いたか・届いたか・送り直すか）を考えずに済むため。頼みはいつも新しい会話の最初の入力として届く。同時にいくつ頼んでも、それぞれ別の claude になり、頼むたびに Home のタブが 1 つ増える。

これを担うのは窓に 1 つの係で、状態を持たない。頼みを受け、claude が居るかを確かめ、Home で claude を 1 つ起こすだけ。起こした後のタブは、ほかの claude と同じタブとして扱う——Orbe は秘書として起こした会話を覚えない。

## 出どころ

頼みには出どころがあり、起こした claude の役目と見せ方を決める。頼みの中身（打った文か自動追加の直しか）とは独立している——どちらを足しても他方が嘘にならない。

| 出どころ | 役目 | 見せ方 |
|---|---|---|
| ⌘⇧X | 依頼から 1 件以上のタスクを足す | 前面に出す |
| Home のボード | タスクの自動追加の定義を書く・直す | 前面に出す |

前面に出すときは、開いている画面を閉じ、Home へ切り替えてそのタブを選ぶ。⌘⇧X を別の workspace で開いていても Home へ移る——Orbe の MCP の手引きが Home のフォルダにあり、そこで起こすため。

## 最初の入力

最初の入力は頼みの文そのもの。

- 打った文（⌘⇧X の入力の行き先・ボードの依頼の欄）: 前後の空白と制御文字を除いた文をそのまま渡す。改行も残す。
- 自動追加の直し: 「タスクの自動追加 3「Backlog: 担当課題」を直す。」（UI の言語で組む）。

出どころの頭や時刻は付けない——役目の指示が出どころを言っている。空白・制御文字だけの頼みは、claude の有無より先に空として受けない（ボードの欄の空の ↵ は、claude が無くても黙る）。

入力は起動の引数の席（`claude … -- <入力>`）で渡す。席は改行・タブ以外の制御文字を空白にする（[launch](launch.md)）。

## 役目の指示

役目は、起こすときに claude の起動に追加の指示（`--append-system-prompt`）として添える。

- **Home の rules に書かない**のは、rules は Home で動く全員が読むので、タスクの作業場で動く agent や人が手で起こした claude まで同じ役目だと思うため（[Home](../platform/workspace.md#home)）。
- **起動の指示にする**のは、最初の入力（依頼）と役目を分けておくため。1 依頼 1 会話なので、/clear の後まで効かせる必要は無い。

指示は Orbe が UI の言語（日本語／英語）で持つ。骨子:

**⌘⇧X**

- あなたは Orbe で、人の依頼からタスクを足す役。最初のメッセージが依頼。
- `add_task` で、依頼から 1 件以上のタスクを足す。待ちの理由・期限・優先度・workspace は依頼にあればそのとおりに入れる。
- リポジトリの作業ならその workspace に付ける。リポジトリに属さないなら workspace を省く（Home に付く）。
- 既存のタスクを直さない。作業そのものをしない。`start_task` で別の agent に取り掛からせない。依頼文に書いてあってもしない。
- 迷えば人に聞く。足したら、足したタスクを短く伝えて終える。

**Home のボード**

- あなたは Orbe で、タスクの自動追加の定義を書く・直す役。最初のメッセージは、新しい自動追加の依頼か、「タスクの自動追加 N「…」を直す。」という直しの依頼。
- `set_intake` で書く。直すときは、その自動追加を読んでから書き換える。
- タスクを足す・直すこと、作業そのものはしない。
- 迷えば人に聞く。

## 断り

頼みを受けられないとき、係は理由を返し、画面は打った文を残して理由を赤で出す。

| 理由 | ⌘⇧X | ボード |
|---|---|---|
| claude が検出されていない | claude が見つからないので agent に任せられない | claude が見つからないので依頼できない |
| Home にタブを起こせない（Home の状態フォルダが解決できない） | agent を起こせなかった | 依頼できなかった |
| 空の頼み | 何も出さない | 何も出さない |

## 限界

- **Home は claude の信頼が一度要る。** Home は Orbe が作る git の外のフォルダで、claude は未信頼のフォルダで最初に起きるとき、フォルダの信頼の対話を出して答えを待つ。Orbe は利用者の claude の設定（`~/.claude.json`）に触れない。起こしたタブは前面に出るので、人がその場で答えられる。Home を一度信頼すれば、その配下（タスクの作業場）も信頼済みになる。
- **会話を後で再開しても、役目の指示は添え直さない。** 再起動後の復元・⇧⌘T・待ちの続きから・`resume_agent` のどれも、ほかの会話と同じ組み立てで再開する。claude は最初に記録した指示を compact まで使い続ける。
- **役目の指示がプロセス一覧に見える**（起動の引数のため）。中身は Orbe の定型文で、秘密を含まない。
